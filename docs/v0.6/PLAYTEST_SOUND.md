# v0.6 SOUND STAGES — 人間の試遊ガイドと評価シート

AI の客観検証（[研究記録](research_log/V06_SOUND_LOG.md)）とは別に、**人間の耳と主観**を記録するためのシート。
ここに書く項目は、すべて**未検証**（人間が聴くまで分からない）。

## 開き方
- スマホ（推奨）：https://research-v0-6-sound.asmr-musou.pages.dev/stages.html
- 比較用：同じビルドの `/feel.html`（v0.5）。全ステージを開く：`/stages.html?all=1`。v0.5 と同じ音のバランスで聴く：`/stages.html?mix=v05`
- **イヤホン推奨。** 縦画面・片手で。最初のタップで音が出る。

## 進め方（約15分）
1. **初めての人として**、`/stages.html` を開き、Stage 1 → 2 → 3 の順に遊ぶ（キャラは好きなもの）。素材の紹介カードは初めて出会ったときだけ出る。
2. Stage 3 をもう一度、別のキャラで遊ぶ。
3. `/stages.html?mix=v05` で Stage 3 を遊び、音のバランスを聴き比べる。
4. ASMR図鑑で、3素材 × 3キャラの音を聴き比べる。

## 最後に答えてほしいこと
1. 3素材のうち、一番好きな音と、違いが分かりにくかった組み合わせ。
2. 12秒のソロは長すぎ／短すぎ／ちょうどよい？
3. 「今日はこの素材の音を聴きたいからこのステージ」と思えたか。
4. Stage 4（チョーク）以降に期待すること。導入順の希望（依頼書の仮案：チョーク → 砂 → 吸水スポンジ → 粒入りスライム → 琥珀糖）。

## 未検証のまま残っていること
- 音の聴き取りやすさは、エネルギー比（AI の代理指標）でしか測っていない。人の耳でのマスキングは未検証。
- スマホのスピーカーとイヤホンでの聴こえ方の違い。
- Android 実機での性能（PC で CPU を4倍遅くした条件でのみ計測）。
- 素材の音そのもの（v0.3 の合成音）は変えていない。
