# v0.6 SOUND STAGES — 研究記録（総監督）

数値の全表は [research/v06/summary.md](../../../research/v06/summary.md)（`node tests/sound/summary.mjs` で再生成）。人間の評価は [PLAYTEST_SOUND.md](../PLAYTEST_SOUND.md)（未検証）。

## 1. 技術の選択
| 決めたこと | 理由 |
|---|---|
| v0.5（`research/v0.5-feel`）から `research/v0.6-sound` を作り、別ページ `stages.html` にした | v0.5 の `feel.html` を比較用にそのまま残すため。`feel/heroes.js`（操作）は共有し、変更しない |
| `feel/game.js` を `stages/game.js` に写して改造した | 敵の出し方・ボス・結果画面は v0.5 の内部関数で、外から差し替えられない。v0.5 側を変えずに済む |
| `feel/sfx.js` には「使わなければ何もしない」2つの口だけを足した（`C.sfxGain`：効果音の大きさ、`C.sfxContext`：別の音声コンテキストへ描画） | ステージの音のバランスと、オフラインの音の計測に必要。v0.5 では未設定なので挙動は同じ（v0.5 のシミュレーションで確認） |
| 素材の音のバランスは、v0.3 の音響エンジンの `play` を外から包んで変えた（`stages/stages.js`） | エンジン本体（`lab/audio`）は変えない。v0.3 の素材研究所・v0.4・v0.5 に影響しない |
| 音の聴こえ方は、同じプレイを2通りのミックスでオフライン描画して比べた | 実時間で録音すると毎回プレイが変わる。同じ出来事の列を描き直せば、ミックスの違いだけを比べられる |
| 素材ごとの音は「ほかの音も発音枠には入れたまま、聞こえない大きさにする」方法で分けた | 同時発音の上限（24）で省かれる音が、全体のミックスと同じになる |
| 有料サービス・Codex は使っていない | 依頼どおり。すべて既存の環境（Node、Playwright、Chrome）で実施 |

## 2. 導入順の検証（音の特徴量）
- 8素材の合成音（切断音・打撃音・粒の音）を描画し、長さ・立ち上がり・明るさ（スペクトル重心）・ノイズっぽさ・低音/高音の割合・細かい破裂の数を測った。それぞれを標準化し、素材どうしの距離を出した（`tests/sound/analyze.mjs`）。
- 依頼書の順（ロウ → ゼリー → 石鹸）は、新しい素材と既に知っている素材の最小距離が 4.0 → 3.8。8素材の中では離れている方なので、そのまま採用した。
- 近くて聴き分けにくそうな組：吸水スポンジ↔琥珀糖 1.6、ロウ↔琥珀糖 1.9。Stage 6・8 の前に、音の作り分けが必要かもしれない（未検証）。

## 3. 失敗と直し方
| 何が起きたか | 原因 | 直し方 |
|---|---|---|
| Stage 1 の魔法使いだけ弱い（強化前の一手の最大 31.5 → 19.3体） | 雷は濡れた素材しか伝わらない。ロウは乾いている | ステージの主役の素材は、雷を通すことにした（Stage 1 で 34.5体） |
| ボス戦の音の 94〜97% がキャラの効果音 | 割れない一撃では「ドン」しか鳴らず、素材の音がほぼ出ない（v0.5 からの仕様） | 一撃ごとに、その素材自身の打撃音と、削れる粒の音を鳴らす。「ドン」は 18% に下げた |
| ASMR図鑑で、拳闘士だけ3回殴っても1体しか壊れない | 殴った敵が飛んでいき、床に落ちるまで次が出ない | 図鑑の敵は、殴るとその場で割れるようにした |
| 上の情報欄でキャラ名が改行、ステージ札で素材名が折り返す | 欄が狭い | ステージの印を別の行にし、ステージ札を「遊べる3つは大きく、予告の5つは小さく」した |
| 新素材の紹介カードが、出てきた群れに重なる | カードを画面の上の方に置いていた | 群れのいない、キャラの上へ移した |
| 素材の色の印が実物と逆（ゼリーを水色、石鹸を紫にしていた） | 素材の絵の色を確かめずに決めていた | 画面の色を実測して合わせた（ロウ＝くすんだピンク、ゼリー＝紫、石鹸＝ミント） |
| 図鑑の追加でページが動かなくなった | 1行のコードの途中に `//` のコメントを入れ、行の残りを消していた（v0.5 でも一度起きた） | ブロックコメントに直した。`node --check` で構文を確かめる |
| 音の計測を3つ並行で流したら、拳闘士の回で進まなくなった | Chrome のオフライン音声描画（OfflineAudioContext）が3つ重なると極端に遅くなる（単独なら約25秒） | 順番に1つずつ流す。結果は1件ごとに保存する |

## 4. v0.5 の操作と破壊快感を損なっていないか（AI の客観検証）
同じ自動プレイヤー・同じ4つの戦場で、v0.5（`feel.html`）と v0.6 の Stage 1〜3 を比べた（`tests/sound/sim.mjs`）。人間らしいプレイヤー＝群れの濃い所を見て、大剣士はそこをスワイプ、ほかはそこをタップする。

| キャラ | 一手あたりの撃破 v0.5 → Stage 1 / 2 / 3 | 一手の最大（強化後）v0.5 → Stage 1 / 2 / 3 | ボス撃破 |
|---|---|---|---|
| 大剣士 | 13.2 → 12.6 / 15.2 / 12.9 | 55.0 → 52.8 / 56.0 / 53.3 | すべて 4/4 |
| 拳闘士 | 9.8 → 10.0 / 10.0 / 11.1 | 60.5 → **46.5** / 53.8 / 51.5 | すべて 4/4 |
| 魔法使い | 14.1 → 14.3 / 14.2 / 13.6 | 57.0 → 55.3 / 57.5 / 56.8 | すべて 4/4 |

- 一手あたりの撃破は、どのキャラ・ステージでも v0.5 の −5%〜+15%。最初の撃破は 0.3〜0.4秒で変わらない。
- 拳闘士の Stage 1 だけ、一手の最大が下がった（平均は同じ）。ロウだけの群れでは、殴り飛ばした敵の玉突きが短くなる。物足りなさとして感じられるかは**未検証**。調整案：ロウの硬さ（`C.MAT.wax.hard` 1.3）をステージでは下げる。
- でたらめに触るプレイヤーでも、一手あたりは v0.5 と同程度（8.1〜9.2 → 8.4〜10.2）。
- ボスだけを倒す時間は、素材を変えても v0.5 と同じ（例：大剣士 7.0〜7.8秒、拳闘士 8.3〜11.8秒。魔法使いは「大魔法陣＋連鎖拡大」の組み合わせで約15秒、v0.5 も同じ）。ボスの層の素材は、硬さ（叩く回数）に影響しない。

## 6. 新しい素材の音は埋もれていないか（同じプレイを2通りのミックスで描画）
`tests/sound/mix.mjs`：各ステージ×キャラの1プレイ（人間らしいプレイヤー）の出来事をすべて記録し、v0.5 のミックスと v0.6 のミックスでオフライン描画して比べた。「埋もれ」＝主役の素材が鳴っている 50ms のうち、ほかの素材＋キャラの効果音の方が大きい割合。エネルギー比による代理指標で、人の耳のマスキングではない。

| 段階 | 埋もれ v0.5 → v0.6（9通りの範囲） | 主役の素材が音に占める割合 v0.5 → v0.6 |
|---|---|---|
| ソロ | 0〜20% → 0〜15% | 50〜94% → 72〜97% |
| 混ざり始め | 4〜42% → 0〜26% | 39〜91% → 68〜97% |
| 半々 | 0〜65% → 1〜36% | 28〜75% → 55〜98% |
| ボス | 44〜68% → 30〜66% | 2〜6% → 24〜60% |

- 混ざる場面で埋もれる割合は、おおむね半分になった（例：Stage 2 大剣士の「半々」で 64% → 33%、Stage 3 魔法使いの「半々」で 22% → 5%）。
- ボス戦は、素材の音の割合が 2〜6% から 24〜60% に増えた（素材の打撃音を追加したため）。それでも埋もれの割合は 30〜66% と高く、Stage 2 大剣士では 61% → 66% と少し悪くなった（素材が鳴る場面が増え、その多くが効果音と重なるため）。ボス戦の音は次の改善候補。
- 拳闘士は、ソロでも埋もれが 10〜15% 残る。拳の「ドン」が低い音でエネルギーが大きいため。

## 7. 性能（PC の Chrome、CPU 4倍スロットル、音を実際に鳴らした状態）
`tests/sound/perf.mjs`。v0.5 の計測（`input.mjs`）と違い、素材の音響エンジン（メインスレッドで動く）も鳴らしている。

- フレーム時間の95パーセンタイルは、v0.5 が 8.8〜11.8ms、v0.6 が Stage 1 で 4.9〜8.0ms、Stage 3 で 5.7〜12.6ms。素材の種類が少ないほど描画がまとまるので軽い。最も重いのは Stage 3 の大剣士のボス戦（12.6ms、v0.5 は 11.8ms）。どれも 60fps の予算（16.7ms）には収まるが、目標の 8ms は超える場面がある。
- 音の処理（10.7ms ごとの1回分）の95パーセンタイルは 0.6〜2.4ms で、v0.5（1.0〜5.1ms）より重くなっていない。同時発音は、主役の枠を足したため最大 24 → 32。
- Android 実機では未計測。

## 8. 人間が確かめるまで分からないこと（未検証）
- 依頼書の3つの問い（単一素材の音が印象に残るか、新素材で新鮮さを感じるか、混成で音の違いが分かるか）。評価シートは [PLAYTEST_SOUND.md](../PLAYTEST_SOUND.md)。
- キャラの効果音を下げたことで、操作の手応えが弱く感じないか（AI の数値では、操作と撃破は v0.5 と同等）。
- 12秒のソロの長さ、紹介カードの長さ（3.4秒）と位置。
- ASMR図鑑で、キャラによる音の違いが楽しめるか。

## 9. 次の仮説
1. ボス戦では、キャラの効果音をさらに下げるか、一撃ごとの素材の打撃音を少し大きくすれば、埋もれが減る。
2. Stage 1 の拳闘士は、ロウの硬さを下げれば、一手の最大が v0.5 並みに戻る。
3. 共有のアセット（`C:\Dev\AssetsShared` の CC0 音素材など）で素材の音を実録音に置き換えれば、素材ごとの違いがもっと分かりやすくなる。ただし、v0.5 との比較が成り立たなくなるので、人間の試遊のあと、別のブランチで行う。
