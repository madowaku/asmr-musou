## 1. 改善前後（v0.9 ベースライン vs v1.0）の比較と判断理由

### ビジュアル・UI・レイアウト
| 項目 | v0.9 ベースラインの課題（実画面観察） | v1.0 での改善内容 |
|---|---|---|
| **タイトル画面の5人配置** | 右端の ROLLER の顔が SPINNER の腕に隠れてローラーしか見えていなかった | 5人全員の顔がバランスよく収まるアーチ構図に再調整（360×640 および 390×780 のスマホ表示で確認済み） |

| **全8素材の巨大ボス** | Stage 1〜3（ロウ・ゼリー・石鹸）のみ実装 | Stage 4〜8（チョーク・キネティックサンド・吸水スポンジ・粒入りスライム・琥珀糖）の5体の円形巨大ボスアートを新規生成・透過WebP化し、`studio/art/boss-assets.js` に統合 |

### 5キャラクターの操作感と破壊演出（SPINNER の吸い込み旋風を品質基準に）
1. **SLASHER（大剣士：居合斬り）**
   - Codex 実装の `studio/iai.js` を引き継ぎ、URL パラメータ不要の本編標準体験として統合（`?slasher=classic` で比較用に旧版へ切替可）。
   - 抜刀時の鞘鳴り＋**115 ms の静寂ダッキング**、レベル別の斬線色変化、断面開花時の閃光リング、長押しの大回転居合、成長後の二連居合・残心衝撃波を追加。
2. **CRUSHER（拳闘士：打撃と玉突き連鎖）**
   - 従来の `rayCount >= 2` 制限を緩和し、`rayCount >= 1` かつ ±55° の自動エイムで仕留めパンチを積極的にビリヤード弾化。
   - 玉突き飛行中のピンク軌跡、衝突ごとのヒットストップ・衝撃波リング、連鎖世代に応じてペンタトニック上昇する `billiard` 効果音、「玉突き×N」ポップを実装。
3. **CASTER（魔法使い：集合・圧縮・一斉破裂）**
   - タップでもミニ重力魔法陣が出現して周囲を引き寄せ圧縮→破裂。そのまま押し続けると途中で暴発せずシームレスに大重力圧縮へ合流する操作体系へ改善。
   - チャージ中の `squash` 圧縮変形が物理減衰に負けて見えなかった不具合を修正し、渦巻き吸引＋幾何学六芒星魔法陣＋主素材の持続圧縮音 (`strain`) → 一斉ウェーブ破裂を実現。
4. **SPINNER（双剣士：吸い込み旋風と連続切断）**
   - 好評の円認識・接線連続切断・吸い込み旋風をそのまま維持しつつ、Lv1 初期段階から穏やかな旋風引き寄せを付与して初動の空振りを軽減。
5. **ROLLER（圧延士：連続的な変形と圧延）**
   - Codex 実装の `studio/roller-feel.js` / `roller-render.js` を本編標準へ統合し、全8素材（チョークの粉帯、砂の砂紋と流動音、スポンジの濡れ色変化と水滴、スライムのビーズ散乱、琥珀糖の結晶片）に対応。

### 音響エンジンとミックス（`studio/audio-polish.js` + 48kHz オフライン波形解析）
- **居合の静寂**: `iai_draw` 時に 115 ms のダッキングを掛け、静寂の後に左右ステレオへ順番に素材断面音が開花することを確認（ステレオ幅 14.6%）。
- **圧縮持続音・圧延音**: CASTER 圧縮中および ROLLER 圧延中の連続 `strain` / `wobble` / `flow` ストリームと解放ウェーブの遷移をスペクトログラムで視認確認。
- **大群破壊でも耳が疲れないミックス**: 同時発音密度に応じた 4.2 kHz 以上の動的ハイシェルフ減衰を追加。36体混成ウェーブ（`horde_36_mixed`）でも 9 kHz 超エネルギー比率 **0.01%**、クリッピング（リミットサンプル）**0**、同時ボイス最大 **20**（上限24以内）、スマホスピーカー帯域（500–8000 Hz）比率 **99.8%** を確認。
- **巨大ボス破壊の解放感**: 外殻・中殻ブレイク時に `0.34 s` の演出クッション＋層ブレイク和音 (`boss_layer`)、最終コア破壊時に多段ステレオ解放コード (`finale`) を追加。

### コンテンツ（8素材・8ステージ・ASMR図鑑）
- 全8素材（ロウスクイーズ、ゼリー、石鹸、チョーク、キネティックサンド、吸水スポンジ、粒入りスライム、琥珀糖）の 8 ステージを実装し、クリア進行に応じて順次解放。
- ASMR図鑑では時間制限・侵入・成長なしで単体／複数配置／連続供給を自由に楽しめ、プレイ中フッターの**「キャラ変更」ボタン**で同じ素材を5人全員で即座に壊し比べられるようにした（5キャラ × 8素材 = 40通り）。

## 2. 確認できたこと / 未確認のこと（正直な記録）

### 確認できたこと
- Playwright + Chrome モバイルエミュレーション（390×780 および 360×640）での全8ステージ攻略・全8体ボス撃破・5キャラ固有破壊挙動・ASMR図鑑（全8素材解放＆ワンタップキャラ切替）・エラー 0 件・切断フォールバック 0 件。
- スクリーンショットの目視確認（タイトル5人配置、8ステージ一覧、5キャラ破壊シーン、全8巨大ボスのシームレス描画、進化ダイアログ、結果画面、図鑑一覧、360×640 コンパクトスマホ表示）。
- Node.js オフライン 48 kHz ステレオ WAV 書き出しおよび Python 波形・スペクトログラム可視化による音響指標の確認（全8素材・居合静寂・CASTER圧縮破裂・ROLLERスポンジ圧延・36体大群ミックス）。

### 未確認のこと（人間による実機試遊で確認が必要な項目）
- **スマートフォン実機（Android / iOS）** でのタッチ追従性、指の疲れ、実フレームレート、画面サイズごとの体感。
- **人間の耳による聴感評価**（波形・スペクトログラム・LUFS・帯域比率の数値検証までは実施したが、実際のスピーカー／イヤホンでの「心地よさ」「静寂の間の長さの好み」「5キャラ間の音量バランス」は実聴確認が必要）。
- 60秒間の難易度曲線や全8ステージを通しプレイした際の飽きにくさ・楽しさの主観評価。
