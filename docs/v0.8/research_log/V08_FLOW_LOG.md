## 1. 技術の選択
| 決めたこと | 理由 |
|---|---|
| `research/v0.7-tempo` から `research/v0.8-flow` を作り、`tempo/game.js` を `flow/game.js` に写して改造した | TEMPO（`tempo.html`）を比較用にそのまま残すため |
| SPINNER は別ファイル `flow/spinner.js` にした。操作の共有ファイル（`feel/heroes.js`）は変えていない | 既存3キャラの操作をそのまま残すため。必要な関数（移動・範囲・攻撃の入口）は既に外から使える |
| `feel/sfx.js` には新しい音「twin」（双剣のシャッ）を1つ足しただけ | 古いページからは呼ばれない |
| 攻撃ごとの威力は `C.hit` に渡せるようにした（`{action, dmg}`） | 双剣士の「一刻み」は通常の一撃より弱いため |
| 破片の片付け（体と破片が140を超えたら、1.4秒より古い破片から消す）は FLOW 側で行った | 共有の物理（`combat/world.js`）を変えないため |
| 有料サービス・Codex・画像生成は使っていない | 依頼どおり。双剣士の絵も手続き描画 |

## 2. TEMPO との比較（4戦場 × キャラ、同じ外部ボット。連打＝約0.42秒ごと、のんびり＝約0.8秒ごと）
段階は時間（開幕0〜12秒、成長12〜24秒、大群24秒〜ボス）。FLOW は強化の時刻が人によって違うので、レベル別の数字も出した。

### 敵を待っている時間
| | 開幕 | 成長 | 大群 |
|---|---|---|---|
| 大剣士 連打 TEMPO → FLOW | 0% → 19% | 33% → 23% | 58% → 54% |
| 大剣士 のんびり | 0% → 1% | 28% → **8%** | 46% → **20%** |
| 拳闘士 連打 | 0% → 2% | 3% → 0% | 3% → 0% |
| 魔法使い 連打 | 0% → 27% | 37% → 52% | 57% → 65% |
| 魔法使い のんびり | 0% → 6% | 19% → 18% | 51% → **43%** |
| 双剣士（FLOW のみ） | 0% | 0% | 0% |

- 人に近いテンポ（のんびり）では、大剣士の待ちが大きく減った（大群 46% → 20%）。魔法使いは少し減った（51% → 43%）。
- **連打では、大剣士と魔法使いの待ちは減らなかった**（魔法使いは開幕で増えた）。FLOW では開幕の敵が1〜2回で壊れる段階に早く進む（5〜6秒で Lv2）ため、開幕の時間帯から「一撃で消える」状態になる。行列の補充は、全力の連打に追いつかない。

### 1秒あたりの攻撃・一体を壊す回数・一撃あたりの撃破
| | 1秒あたりの攻撃（開幕/成長/大群） | 開幕の一体の打数 | 一撃あたりの撃破 Lv1 → Lv2 → Lv3 → Lv4 |
|---|---|---|---|
| 大剣士（のんびり） | 1.20 / 1.20 / 1.16 | 2.3 | 0.62 → 5.8 → 21.9 → **31.4** |
| 拳闘士（のんびり） | 1.32 / 1.26 / 1.27 | 1.9 | 0.62 → 2.7 → 10.7 → 32.3 |
| 魔法使い（のんびり） | 1.32 / 1.24 / 1.27 | 1.8 | 0.69 → 5.6 → 23.2 → 27.6 |
| 双剣士（のんびり、1刻み＝1攻撃） | 3.52 / 3.35 / 3.40 | 2.8 | 0.24 → 1.2 → 5.5 → 8.7（1周≒5〜7刻み） |

- 攻撃の頻度は、開始から終了までほぼ一定のまま、一撃で壊れる量が成長で約0.6体 → 約30体に増えた（依頼の目標の形）。
- TEMPO（時刻で強化）の大群での一撃あたりは 26〜37体。FLOW の Lv4 は 27〜32体で、ほぼ同じ水準に戻った（途中の調整で、行列を重ならないように並べた分、一度は約15体まで下がった。§4）。
- 「開幕の一体の打数」が TEMPO の約3回より少ない（1.3〜2.3回）のは、開幕の12秒の間に Lv2 になり、以後の敵が一撃になるため。Lv1 の間は約3回（拳闘士は約2回）。

### レベルアップ（CRUNCH ENERGY）
| | Lv2 | Lv3 | Lv4 |
|---|---|---|---|
| 到達時刻（連打） | 5.3〜7.8秒 | 15〜21秒 | 27〜36秒 |
| 到達時刻（のんびり） | 7.6〜10.6秒 | 18〜28秒 | 30〜43秒 |
| それまでの撃破数 | 6〜8体 | 58〜72体 | 233〜400体 |

- 全員がボス（42秒）の前後までに Lv4 に届いた（のんびりの拳闘士だけ 42.6秒）。依頼の「ボス戦に入るまでに自然に成長」はおおむね満たした。
- エネルギーの内訳は、ほとんどが撃破（削りは全体の3〜15%）。

### 追撃・ボス・侵入
| | 追撃の命中 | ボス撃破 | 侵入（1プレイ） |
|---|---|---|---|
| 大剣士・拳闘士・魔法使い | 92〜100% | 4/4（3〜10秒） | 0.5〜2.8 |
| 双剣士 | 48〜58% | 4/4（6〜9秒） | 2.8 |

- 双剣士の追撃の命中が低いのは、円を描いている間に狙った敵が先に壊れ、残りの刻みが空を切るため（ボットは同じ大きさの円を描き続ける）。人がどう感じるかは未検証。
- 侵入は TEMPO（0）より増えた（行列で敵が絶えず下りてくるため）。防衛の緊張感としてよいか、強すぎるかは未検証。

## 4. 失敗と直し方
| 何が起きたか | 原因 | 直し方 |
|---|---|---|
| 書き換えのスクリプトが途中で止まった | シェルの「ここから文書」の中に、閉じていない引用符があるように解釈された | 書き換えのスクリプトをファイルにして実行した |
| 結果画面の関数が閉じなくなった | 1行を置き換えたとき、行末の `}` まで消していた | 戻した。`node --check` で構文を確認 |
| 強化が速すぎた（Lv2 が約5秒、Lv4 が約21秒） | 必要量が小さい | 必要量を 60/150/320 → 90/240/480 → 90/240/400 にした |
| 双剣士の撃破が他の半分以下、侵入が最大15回 | ①円の中心を「キャラが立てる範囲」（y≥250）に押し込めていて、上の方の敵に刃が届かなかった。②一刻みが弱すぎた | ①刃の円は指が描いた場所に出す（キャラの位置だけ範囲内に）。②一刻みの威力 0.55 → 0.75、刻みの間隔 52° → 43° |
| 揺れのある楕円で、1周に29回も刻んだ | 刻みを「線の向きの変化」で数えていたので、手の震えも回転として数えた | 刻みは「円の中心から見た指の角度」で数える。認識（円かどうか）は向きの変化のまま |
| 敵が画面の上端（HUD の裏）に溜まった | 待機列の場所と「届く位置」の境目が上に寄りすぎていた | 待機列を y=150〜400、届く位置を y≥400 にし、HUD の裏では急いで進む |
| 終盤の一撃あたりの撃破が TEMPO の約半分（約15体） | 敵が重ならないように並べた分、届く位置の数が少ない | 古い破片を早めに片付けて描画の余裕を作り、終盤の目標数を 16/22 → 24/32 に、待機列の補充を速くした（Lv4 で 27〜32体） |

## 6. ゼリーの三角形分割エラー
切断の失敗は FLOW でも内部で起きることがある（4キャラ×2プレイで0〜1回）が、その敵はその場で粉になって消え、撃破として数えられ、ゲームは止まらない（TEMPO と同じ保護）。失敗そのものを防ぐ（削りすぎた形を作らない）のは次の課題。

## 7. 人間が確かめるまで分からないこと（未検証）

- CRUNCH ENERGY で「成し遂げて強くなった」と感じるか。ゲージは見やすいか。
- 双剣士の「指を回す気持ちよさ」、疲れ、指で画面が隠れないか。

## 8. 次の仮説
1. 連打する人の大剣士・魔法使いの待ち：行列の前進をもっと速くするより、「Lv2 になるまでの開幕を少し長く」（必要量90を増やす）方が、一体を削る時間が残って暇も減る。
2. 双剣士の追撃：狙った敵が壊れたら、円の中心を次の敵へ少し寄せる（吸着）。
3. 削りすぎた形を作らない：頂点が多すぎる体は、削らずに亀裂だけにする。
