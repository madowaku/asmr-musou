# v0.8 CRUNCH FLOW — 人間の試遊ガイドと評価シート（すべて未検証）

## 開き方
- スマホ：https://research-v0-8-flow.asmr-musou.pages.dev/flow.html
- 比較用（v0.7 TEMPO）：同じビルドの `/tempo.html`
- 縦画面・片手で。イヤホン推奨。Android 実機での動作・音・操作感は、この試遊で初めて確かめる。

## 進め方（約12分）
1. TEMPO（`/tempo.html`）を大剣士か魔法使いで1回。
2. FLOW（`/flow.html`）を4キャラで1回ずつ。最後は SPINNER（双剣士）をもう1回。

## 一番確かめたいこと
| 問い | 大剣士 | 拳闘士 | 魔法使い | 双剣士 | メモ |
|---|---|---|---|---|---|
| 開始から終了まで、自分から次の一撃を出したくなったか（1〜5） | | | | | |
| 暇だと感じた時間はあったか（いつ、どのくらい） | | | | | |

## A. 敵の行列
| 問い（1〜5） | 評価 | メモ |
|---|---|---|
| 奥に次の敵が見えていて、手前が空くと前に出てくる流れが自然か | | |
| 成長後の大剣士・魔法使いでも、攻撃したい場所に敵がいたか | | |
| 敵が多すぎて、素材や壊れ方が見えなくなる場面はなかったか | | |
| 防衛ラインの緊張感はちょうどよいか（侵入が増えた場合も） | | |

## B. CRUNCH ENERGY
| 問い（1〜5） | 評価 | メモ |
|---|---|---|
| 「自分が壊した結果、強くなった」と感じたか（v0.7 の時間で強くなるのと比べて） | | |
| ゲージが貯まっていくのが気持ちよく分かったか（小さすぎないか） | | |
| LEVEL UP の間隔はちょうどよいか（早すぎ／遅すぎ） | | |
| 強化したとき、武器と攻撃の見た目の変化に気づいたか | | |
| 最初は何度も削った敵が、一撃で壊れるようになって気持ちよかったか | | |

## C. SPINNER（双剣士）— 自動テストでは判断できない
| 問い（1〜5） | 評価 | メモ |
|---|---|---|
| 説明を読まずに、円を描けばよいと分かったか | | |
| 指の動きと、キャラの回転・切断・音が一致していると感じたか | | |
| 円を描くと「サクサクサクッ」と連続して切れる気持ちよさがあったか | | |
| 小さい円で一体を刻む、大きい円で群れを巻き込む、の違いが分かったか | | |
| ゆっくり小さく回しても気持ちよかったか。指は疲れなかったか | | |
| 速く回したとき、追加の爽快感があったか | | |
| 円を描いている最中も、素材の壊れ方が見えたか（指で隠れなかったか） | | |
| 描いたつもりがないのに回転斬りになった／円を描いたのに回らなかった場面 | | |
| タップ（クルッ）、スワイプ（駆け抜け斬り）、長押し（大旋風）は分かりやすかったか | | |
