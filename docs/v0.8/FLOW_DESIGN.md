# ASMR MUSOU：CRUNCH FLOW v0.8 — 途切れない破壊 × 達成による成長 × 双剣士 SPINNER（総監督）

試遊ページ：`flow.html`（比較用の v0.7 TEMPO `tempo.html`、v0.7 `crunch.html` は同じビルドにそのまま残す）

> 素材を壊したくて指が動き、その結果どんどん強くなり、さらに壊したくなる。

## 0. 出発点（v0.7 TEMPO の人間による試遊結果）
- 序盤の待ち時間は0%になり、一体を何度も削る楽しさが生まれた。
- それでも全体的に暇な時間がある。とくに大剣士と魔法使いは、成長すると周りを一撃で消してしまい、次を待つ。
- 12秒・24秒で自動的に強くなるより、**自分が何かを成し遂げた結果として**強くなりたい。

## 1. A. 途切れない敵の行列
敵が突然湧くのではなく、**奥（画面の上の方、y=150〜400）に次の敵が並んで見えていて、手前が空いたら前に出てくる**。

| しくみ | 内容 |
|---|---|
| 待機列 | 画面の上から歩いて入ってきた敵は、y=150〜400 の「待機列」に見えている。HUD の裏（y<150）には留まらない |
| 前進 | 「届く位置」（y=400〜ライン）の敵が目標数より少ないと、待機列の敵が最大4.5倍の速さで前へ詰める（ベルトコンベアのように見える） |
| 重ならない | 敵は前の敵にぶつからず、その後ろで待つ（縦に並ぶと行列になる）。素材・亀裂・断面が重なって見えなくならない |
| 段階（レベルで変わる） | Lv1：大きな敵が4本の列に1体ずつ（届く位置に3体）。Lv2：4〜5体の横一列（8体）。Lv3〜4：画面幅いっぱいの横一列（9〜10体、24〜32体）＋硬い新型。広い一撃のすぐ外にも敵がいるようにした |
| 描画の予算 | 体と破片の合計が140を超えたら、1.4秒より古い破片から片付ける（落ちて画面の外へ向かうもの）。その分を敵に回す |

## 2. B. CRUNCH ENERGY（壊して強くなる）
時間で強くなるのをやめ、**壊したエネルギーで LEVEL UP** する。

| 得るもの | エネルギー |
|---|---|
| 削り | 実際に切り落とした面積（その敵の最初の大きさに対する割合）× 8 × 大きさの補正。空振りや、削れなくなった小さなかけらを叩いても増えない |
| 撃破 | 敵の大きさで変わる：大きな敵10、群れ3.2、大群1、硬い新型18、ボスの層2 |
| 大きな一撃 | 一回の攻撃で6体以上壊すと、撃破数×0.12（最大12）のボーナス |
| 追いつき | いつもの到達時刻（Lv2：12秒、Lv3：24秒、Lv4：34秒）を過ぎると、遅れた秒数に応じて得られる量が最大4倍まで増える。強化が遅い人でも、弱い時間が長引かない |

- 必要量：Lv2 まで90、Lv3 まで240、Lv4 まで400（強化は最大3回）。
- 到達すると時間が止まり、2択の強化を選ぶ。どちらを選んでも**威力が上がる（1 → 3 → 5 → 7）**。
- 強化のたびに見た目が変わる：刃の軌跡の色と太さ（淡い色 → ピンク → 金 → 虹色に移り変わる）、キャラの周りの輪が増える。
- HUD：上の細いゲージ「Lv n ━━━ CRUNCH」。エネルギーを得るたびにゲージが光る。
- ボスは42秒に出る（60秒は維持）。

## 3. C. SPINNER（双剣士）
**指でくるくる円を描くと、双剣士がそこで回転しながら、2本の刃で周りの素材を細かく刻む。**

| 指の動き | 起きること |
|---|---|
| 円を描く（同じ向きに約190°曲がると認識） | 回転斬り。指が円の中心のまわりを約43°回るごとに「刻み」が1回。刻みの円の大きさは、描いた円の大きさ（小さい円で一体を細かく、大きい円で群れごと） |
| ゆっくり回す | 指が動いている間は、少なくとも0.3秒ごとに刻む。速く回さなくても気持ちよく続く |
| 速く回す | 刻みが増える。回転がつながる（0.4秒以内の連続）ほど、刻みが少し深くなり、刃の音が少し高くなる |
| タップ | その場で「クルッ」（3回の刻み） |
| まっすぐスワイプ | 駆け抜け斬り（線の上の敵を一度ずつ切る） |
| 長押し → 離す | 大旋風（8回の刻み。溜めるほど大きい） |

- 刻みは、敵の中心を通る「円の接線」に沿って切る。倒しきれない敵は、刻みのたびに削れていく（形・断面・ひびの音）。
- 強化：大旋風（範囲1.4倍）／四刀流（刃4枚、刻みが深い）／吸い込み旋風（回すたび周りの敵が円の中へ寄る）。
- 音：刻みごとに、左右交互の「シャッ」。回転がつながるほど少し高くなる。
- 円の認識は「進む向きの曲がり具合」で行う（中心を推定しなくてよいので、いびつな円や楕円でも認識できる）。刻みの数は「中心から見た指の角度」で数える（手の震えで刻みが増えすぎない）。

## 4. 既知の不具合
何度も削ったゼリーを砕くと、三角形に分割できない形ができることがある（v0.7 から）。v0.8 では TEMPO と同じく、切断が失敗したらその敵をその場で粉にして撃破として数え、ゲームは止まらない。
