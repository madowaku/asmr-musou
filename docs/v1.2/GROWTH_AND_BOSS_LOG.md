# ASMR MUSOU v1.2 — 成長曲線・大剣士多段斬り・多段階ボス戦 開発＆検証記録

- ブランチ: `feat/v1.2-tactile-growth`（既存版 `feat/v1.0-crunch-studio` および `research/*` は保護して併存）
- 対象フィードバック:
  1. 大剣士が強すぎて斬る手応えが薄い → 切断した素材が消えず、断面を開いたままズレてさらに切り分けられる「多段斬り」を実装。
  2. 全キャラがボス戦までに強くなりすぎる → 単発攻撃力の伸びを抑制（`[1, 3, 5, 7]` → `[1, 1.35, 1.75, 2.2]`）し、範囲・連鎖・巻き込み・工程の豪華化で成長を演出。レベル到達ペースを再設計。
  3. 巨大ボスがすぐに倒されてしまう → 単純なHP水増しではなく、外殻→内層→コアの3段階構造と時間配分（全体75秒＝道中45秒＋ボス戦15〜22秒）を再設計。

## 2. キャラクター別・レベル別（Lv1〜Lv4 MAX）破壊工程と攻撃力

全キャラ共通で `K.POWER = [1.00, 1.35, 1.75, 2.20]` とし、アップグレードは攻撃力倍率ではなく **範囲・同時破壊数・巻き込み・連鎖・多段工程** を強化する設計に統一しました（`tests/studio/v12-growth-boss.mjs` による `mid`×6＋`hard`×1 群への2.2秒操作計測）。

| キャラ | Lv1 (`1.00`) | Lv2 (`1.35`) | Lv3 (`1.75`) | Lv4 MAX (`2.20`) | MAX成長時の手応え維持 |
|---|---|---|---|---|---|
| **SLASHER** | `multiSlices: 7` / `kills: 4` | 大斬撃: `multiSlices: 9` / `kills: 5` | ＋衝撃波: `multiSlices: 6` / `hurts: 25` | ＋二重斬撃: `multiSlices: 6` / `hurts: 19` | **1振りで2分割＋ズレ→十字居合で4分割**。静寂・断面・ズレ工程がMAXでも省略されず豪華化 |
| **CRUSHER** | `hurts: 5` / `kills: 4` | ラッシュ: `hurts: 9` / `chainKills: 1` | ＋ぶっ飛ばし: `hurts: 9` / `chainKills: 1` | ＋追加破砕: `hurts: 6` / `kills: 7` | 厚い素材は複数打でヒビ・欠けが入り、吹き飛び→玉突き連鎖が拡大 |
| **CASTER** | `hurts: 15` / `kills: 5` | 大魔法陣: `hurts: 17` / `chainKills: 1` | ＋連鎖拡大: `hurts: 11` / `chainKills: 1` | ＋二重爆発: `hurts: 10` / `chainKills: 2` | 集合→圧縮（歪み＋持続音）→一斉破裂の工程を維持したまま範囲・連鎖が拡大 |
| **SPINNER** | `hurts: 17` / `kills: 3` | 吸い込み旋風: `hurts: 20` / `kills: 7` | ＋四刀流: `hurts: 11` / `kills: 7` | ＋大旋風: `hurts: 10` / `kills: 7` | 吸い込みながらサクサク連続切断する快感を維持（後述の渦テスト参照） |
| **ROLLER** | `rollChips: 8` | ワイド: `rollChips: 16` | ＋重量ドラム: `rollChips: 22` / `kills: 4` | ＋巻き込みフィン: `rollChips: 25` / `kills: 5` | MAXでも押し潰し・ヒビ・圧延跡の再粉砕が省略されず同時巻き込み数が増加 |

### 大剣士 多段斬り 実測値（キネティックサンド単体 / ロウスクイーズ Lv4）
- 初期ブロック面積: `12,743 px²`（1体）
- **1振り目**: 2分割（`after1Count: 2`, `sliceStage: [1, 1]`）、両断面のキャップが開いたまま保持（`after1OpenCaps: 2`）、`0.105s` かけて重心間 `86 px` へ滑らかにズレる（`iai_slide` 発音）
- **2振り目（縦居合）**: ズレた2片をさらに4分割（`after2Count: 4`, `sliceStage: [2, 2, 2, 2]`）
- **3振り目**: 4片をすべて綺麗に切り終えて崩落（`after3Alive: 0`）
- **Lv4（二重斬撃あり）**: 1スワイプでまず2分割＆断面ズレ（`lv4MidHalves: 2`）→ 直後に自動十字居合で4片化
