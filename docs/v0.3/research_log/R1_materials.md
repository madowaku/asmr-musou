## 統合と基盤
| 手法 | 結果 | 判定 |
|---|---|---|
| R2b の音響を研究所に接続（アダプタ） | 群れの波で、`wave` と1体ごとの `cut`/`kill` が二重に鳴っていた → 波が管理する撃破は転送しない。`press`（研究所では1回きり）は音響側では閉じない連続音になる → 転送せず `strain` で代替する。引数の単位も変換した（亀裂 px/s→cells/s、衝突 speed→energy、剥離 area→size） | 採用 |
| デバッグ用イベント履歴 | ゼリーの `wobble` が履歴（上限512件）を埋め、`cut` が押し出されていた → 連続イベントは履歴に入れない | 採用 |
| ゼリーの着地で揺れを再開 | 毎回最大振幅に戻ると収まらない → 衝突の強さに応じて部分的に戻す | 採用 |
| ロウの亀裂線 | 断面の変形（本のように開く）がかからず、片の外にはみ出していた → 変形を適用。切断片では芯が開くまでに消す（柔らかい芯にヒビは入らない） | 採用 |
| ゼリー断面のシェーダー | 不透明で紙のように見えた → 深さで色が変わる半透明ゲル、濡れた縁の光、流れるつや | 採用 |

## 無双（群れ）
| 手法 | 結果 | 判定 |
|---|---|---|
| ばらけた配置（R0-C） | 一振りで約8体しか当たらない | 不採用 |
| 密集隊形（六角格子＋ばらつき） | 帯状の群れになる | 採用 |
| **刃の吸い寄せ**（線が外形をかすめた敵も、刃と平行な線で切る。届く距離は速度に比例して最大34px） | ジグザグの一振りで 13→20体 | 採用（アクションゲームの定番。精密さより爽快感） |
| 群れでも「本のように開く」断面 | 見た目は大きく向上したが、処理時間が2倍（p95 6.1→14.8ms） | 軽量化して採用：開き角はフレームごとに1回計算、小さな雑魚は輪郭の頂点を半分、断面は1層＋切り口の線だけ、頂点変形は作業領域を使い回す → p95 6.7ms |
| 切断片を手前に描く | 未切断の敵の後ろに片が隠れていた | 採用 |
| 雪崩のアクセント位置 | ジグザグでは始点と終点が同じ側にあり、輪が画面端に出た → 最初と最後に倒した敵を結ぶ線に出す | 採用 |
| ロウの群れの亀裂網とチップ | 数十体ぶんの亀裂線とチップが「ピンクの毛玉」に見えた → 雑魚は亀裂網なし、チップは2個 | 採用 |

## 素材別（予兆→解放→余韻）
| 素材 | 実装 | 総監督の評価 |
|---|---|---|
| 石鹸 | 予兆はほぼなし。きれいに切れ、切り口から立方体が不規則な間隔で崩れ、床で跳ねて音を出す | **要改善**：立方体は見えるが「切り口が崩れていく」感じが弱い。次の手は、切り口付近の本体自体をブロック状に溶かすこと（砂の溶解をブロック状のノイズで使う） |
| 砂 | 切り口がギザギザ。本体が前線から溶ける（専用シェーダー）。粒が流れ落ち、床に山ができて約7秒かけてならされる。`flow` を連続で出す | **良い**：「一刀両断→サラサラ→山」がコマ送りで読める。余韻が一番長い素材になった |
| チョーク | ギザギザの切り口。大きい片は60〜120ms後にもう一度折れる（`L.split`）。かけらが跳ね、粉の雲がゆっくり漂う | **良い**：ポキッ…ポキッの連続と粉の余韻 |
| 吸水スポンジ | 長押しで大きく潰れ（倍率2.3）、水を吸って色が濃くなり、しずくが増えていく → 限界で裂けて水がはじける → しずくが垂れる | **良い**：予兆→解放→余韻が最もはっきり見える素材 |
| 粒入りスライム | 切った直後、片同士を糸がつなぎ、弾性で引き戻す。糸は伸びきると1本ずつ切れ（`release`）、粒がこぼれる。`strain` は伸び率に連動 | **要改善**：糸は読めるが、片が回転すると断面が紙飛行機のような尖った形に見える。片の回転を抑えるか、柔らかい本体（ゼリーの変形）を共有する必要がある |
| 琥珀糖 | 外皮（すりガラス状）の帯と、透明な琥珀の内部の二層断面。結晶の破片が飛び、きらめく | **良い**：硬い外殻と柔らかい内部の対比が、一番はっきり出た素材 |

## 失敗・不採用の記録
- ギザギザの切り口（ジッター）は、まれに辺を交差させて三角形分割を失敗させ、フレームループごと止めていた → 分割できない場合は直線の切り口に戻す。フレームループは例外で止まらないようにした。
- 群れ用の簡略断面（ストリップ）は、薄い長方形の板に見えた → 群れでも「本のように開く」断面に統一した。

## 残課題
- 単発で最大約100msのフレームスパイク：テストの補充処理で40体を1フレームに生成しているため。本番の湧きでは、数フレームに分散する必要がある。
- 破片同士・破片と敵の衝突による連鎖破壊（研究計画の「連鎖」）は未実装。
- 石鹸とスライムは上記のとおり要改善。
