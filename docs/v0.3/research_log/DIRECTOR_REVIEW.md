# 総監督レビュー記録（v0.3 研究所）

## Review 1 — R0-A（2026-11-22）
証拠：`research/v03/frames/wax_cut.png`, `jelly_cut.png`, `horde_swipe.png`, `perf_r0a.json`

**評価：技術的には合格、手触りとしては不合格（まだ気持ちよくない）。**
- 合格点：軌跡どおりに切れる（角度誤差3°以内）、面積が保存される、再切断ができる、40/40体、p95 7.1ms。基盤として採用する。
- 問題1「中が見えない」：断面が細い帯で、切った瞬間に内部が見えない。2D の多角形をずらしただけなので、パンを切ったように見える。→ **断面キャップによる立体の錯覚**を試す。切った直後、各片を本のように「開く」（法線方向への疑似的な傾き＝切断線に垂直な方向の縮小と、断面ポリゴンの露出）。断面に内部テクスチャ（ロウならクリーム色の芯と殻の縁）を見せる。
- 問題2「物理が軽い」：片が平行に等速で離れるだけ。重力、回転、床がなく、ヒットストップと閃光も弱い。→ 切断の瞬間に、切断線上の閃光、離れる初速＋回転、重力、画面外へ落ちる動き、切った量に応じたヒットストップを入れる。
- 問題3「ゼリーが硬い」：振動が見えない。→ 振幅をはっきり見えるまで上げる。断面の波打ちと、半分ずつのスカッシュ＆ストレッチ。コマ送りで目に見えることを完了条件にする。
- 問題4「群れに波がない」：全員が同じフレームで切れる。→ R2b の `planWave` で、刃の進行順に時間差で破断させる（見た目と音で同じ時間差）。配置も一直線の人工的なものをやめ、ばらけた群れで試験する。
- 問題5：仮テクスチャのままなので、素材感の評価ができない。→ R0-B の Luna 素材を取り込む（アルファから輪郭を抽出し、断面テクスチャを使う）。
