# v0.3 ASMR素材研究所 — 人間の試遊ガイドと評価シート

目的：8素材を実際に触り、**見た目・音・操作感・「もう一回壊したいか」** を評価する。結果から、本編の主力素材と改善方針を決める。

所要時間の目安：1素材3〜5分 × 8 ＋ 群れ5分 ＝ 約40分。休憩を挟んでよい（耳の疲れも評価対象）。

## 1. 起動
**PC**：`lab.html` を Chrome でダブルクリックして開く（WebGL2 が必要）。最初に画面をタップ／クリックすると音が有効になる。
- 音量は控えめから始める。可能なら、イヤホンとスピーカーの両方で聴く。
- 音だけ確かめたいときは `lab-audio.html`（素材ごとの単発音、予兆のスライダー、撃破数Nの波）。

**Android 実機**（推奨。指で斬る感触は実機でしか評価できない）
1. PC と端末を同じ Wi-Fi につなぐ。
2. リポジトリのフォルダで次を実行する。
   ```
   python -m http.server 8000
   ```
3. 端末の Chrome で `http://<PCのLAN IP>:8000/lab.html` を開く（IP は Windows なら `ipconfig` の Wi-Fi 欄）。
4. 終わったら、PC 側で Ctrl+C を押してサーバーを止める。LAN 内のテスト専用で、公開はしない。

## 2. 操作
| 操作 | 内容 |
|---|---|
| なぞる（スワイプ） | 軌跡どおりに斬る。速いほど勢いよく分かれる。曲がった軌跡は複数に分ける。切れた片はもう一度斬れる（3段まで） |
| 長押し | 押し込む（予兆）。限界まで押すと割れる。スポンジは絞る、ロウは押し込むとヒビが育つ |
| 素材の選択 | 下部のセレクト（PC ではキーボードの 1 と 2 でロウとゼリー） |
| 1体を置く（N） | 選んだ素材を1体置く |
| 群れ（H） | N 体の群れ（既定40体）。密集した隊形。ジグザグに薙ぐと一振りで20体以上を倒せる |
| ¼スロー（S）／一時停止（Space）／1コマ送り（.） | 壊れる瞬間をじっくり見る |
| 録画（R） | 9:16 の WebM を音つきで保存（もう一度押すと保存） |
| ¼リプレイ（L） | 直前のカットをスローで再生（音なし） |

## 3. 素材ごとに試すこと
| 素材 | 試すこと | 注目する瞬間（予兆→解放→余韻） |
|---|---|---|
| ロウ | 斬る／長押しで押し込む | 押すとヒビが育つ → 殻が割れる → クリーム色の芯と殻チップ |
| ゼリー | ゆっくり斬る／速く斬る | 刃が食い込むへこみ → ぷちゅっと分断 → 断面のぷるぷる |
| 石鹸 | 斬る | ほぼ抵抗なく切れる → ショリッ → 立方体がコトコト崩れる（**改善候補**） |
| 砂 | 斬って待つ | ザンッ → 切り口からサラサラ崩れる → 床に山ができる（余韻が一番長い） |
| 吸水スポンジ | **長押し**（約0.5秒）、その後に斬る | 潰れて色が濃くなり、水が染み出す → ザクッと裂ける → しずく |
| チョーク | 斬る | ポキッ → もう一度ポキッ → 粉が漂う、かけらが跳ねる |
| 粒入りスライム | 斬って、片が離れるのを見る | 糸が伸びる → ぷつっと切れる → 粒がこぼれて跳ねる（**改善候補**：断面の形） |
| 琥珀糖 | 斬る | シャリッ → 宝石のような断面 → 結晶の破片が散る |
| 群れ | 群れを出し、ジグザグに一振り／何度も薙ぐ | 刃に沿って割れていく波、撃破数による音の質感の変化（パキッ → バリバリ → 洪水） |

評価の目安：
- **見た目**：素材だと分かるか。切った瞬間に中身が見えるか。壊れ方がその素材らしいか。
- **音**：素材らしいか。耳に刺さらないか。連打しても疲れないか。40体を倒したとき「洪水」「雪崩」に聞こえるか。
- **操作感**：思った線で切れるか。遅れを感じないか。長押しの予兆が分かりやすいか。
- **もう一回**：続けて何度も壊したくなるか。飽きるまでの回数の感覚。

## 5. 最後に答えてほしいこと
1. 本編の主力にしたい素材を3つ（雑魚用とボス用を分けてもよい）。
2. 外してよい素材、または大きく作り直すべき素材。
3. 群れを薙ぐ爽快感は、本編の主軸として十分か。足りないものは何か。
4. 音について：一番良かった音、一番気になった音。
5. 実機の場合：滑らかさ、発熱、文字やボタンの押しやすさ。

## 6. 既知の問題（評価の前に知っておくこと）
- 音はすべてコードで合成した `synth_*` で、録音ではない。
- 石鹸は「切り口から崩れていく」感じが弱い。スライムは、片が回転すると断面が尖った形に見える。
- 破片が別の敵に当たって壊れる連鎖は未実装。
- 群れを出した瞬間に、一瞬引っかかることがある（40体を1フレームで生成するため）。
- 研究所の UI（下部のボタン）は研究用で、本編の UI ではない。
