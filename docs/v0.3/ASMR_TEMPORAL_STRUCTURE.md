# ASMRの時間構造 — 予兆・解放・余韻、そして規模による質感変化（正本・人間の着想を総監督が設計に落としたもの）

## 1. 人間の着想（2026-11-22）
- **ASMRの快感は、破壊の瞬間だけでなく、その直前にもある。** 予兆（圧力がかかって形が歪む）→ 解放（耐えきれず一気に割れる）→ 余韻（破片が落ち、中身が現れる）。
- この3段階の時間配分は素材ごとに違う。石鹸は予兆が短く、砂は余韻が長い。スクイーズは予兆を楽しみ、プチプチは解放を連続させる。**素材には色・形・音だけでなく「快感の時間構造」がある。**
- 大量撃破は音量を上げるのではなく、**撃破数が増えるほど音の質感そのものを変える**。

| 撃破数 | ロウスクイーズ | 石鹸ゴーレム |
|---|---|---|
| 1体 | パキッ | サクッ |
| 3体 | パキパキッ | サクサクッ |
| 10体 | バリバリバリッ | ザクザクザクッ |
| 20体 | バリバリバシャッ！ | ザザザザッ！ |
| 40体 | 殻の割れる音の洪水 | 粒が崩れ落ちる音の雪崩 |

案：破断音を短い時間差で連続させ、最後に素材の崩落音を残せば、音量を抑えたまま規模感を出せるかもしれない。

## 2. 総監督の設計：素材の「快感の時間構造」を共通データにする
`lab/profiles.js` に素材ごとの時間構造プロファイルを置き、**描画・物理・音のすべてがこれを参照する**。音だけ、見た目だけが別の時間で動くことはさせない。

| 素材 | 予兆（pre） | 解放（release） | 余韻（post） |
|---|---|---|---|
| ロウ／スクイーズ | **長い・楽しむ**：0.3〜0.8s。押し込みで歪み、きしむ音と細かいヒビが育つ | 殻が一気にバリッ | 0.4〜0.6s：芯が現れて揺れる、殻チップが落ちる |
| プチプチ | ほぼなし（〜20ms） | **連続する**：解放が連鎖して転がる | 短い：膜がしぼむ |
| ゼリー | 30〜60ms：刃が食い込んでへこむ | ぷちゅっと分断 | 0.6〜1.0s：断面がぷるぷる震える |
| 石鹸 | **短い**：0〜40ms、ほぼ抵抗なし | ショリッと切れる | 0.3〜0.6s：立方体がコトコト崩れて転がる |
| 砂 | 50〜100ms：切れ目から粒がこぼれ始める | ザンッ | **長い**：1.5〜3s。サラサラ崩れて山になる |
| チョーク | 20〜40ms：細いきしみ | ポキッと鋭く折れる | 0.8〜1.2s：粉が舞って漂う |
| 吸水スポンジ | **長い**：押すと水がじゅわっと染み出る | ザクッと裂ける（多孔質） | 0.5〜1s：しずくが垂れる |
| 粒入りスライム | **長い・操作で伸ばせる**：糸を引いて伸びる | 糸がぷつっと切れて粒が散る | 0.6〜1s：粒が跳ねて落ち着く |
| 琥珀糖 | 20〜50ms：外皮に細かいヒビ | シャリッと割れる | 0.4〜0.7s：宝石のような断面がきらめき、内側が柔らかく揺れる |

各フェーズの役割：
- **予兆**：張力が上がっていく（歪み、きしみ、ヒビの成長、粒のこぼれ、糸の伸び）。見た目と音の強さは、圧力や歪みの量に連動させる。
- **解放**：一瞬の鋭い変化（v0.2 の破断フレームの原則：見た目・音・ヒットストップを同じフレームで）。
- **余韻**：重力と減衰の世界（破片、崩落、しずく、粉、揺れ）。音は物理イベント（衝突・流量）に連動させる。

## 3. 規模による質感変化（無双の音響）＝「破断の波」
1. **見た目も音も、刃の進行方向に沿った波として壊す。** 一振りで巻き込んだ敵を、軌跡上の位置順に並べ、数ms〜十数msずつずらして破断させる。見た目の破断フレームとそれぞれの音を一致させる（波が届いた敵から割れていく）。
2. **撃破数の段階**で質感を変える（単なる音量変化ではない）：

| 段階 | 撃破数 | 波の長さ | 個々の破断音 | 末尾 |
|---|---|---|---|---|
| 単発 | 1 | 0 | 素材の解放音（フル） | 素材の余韻 |
| 連打 | 2〜4 | 40〜80ms | 解放音を少し短く・小さく。v0.2 のストローク内で上がる音階を維持 | 余韻 |
| ラッシュ | 5〜12 | 120〜220ms | 先頭3体だけフル、残りは粒状の短い破断音に（パキ → バリ） | 余韻を少し長く |
| 雪崩 | 13〜25 | 220〜350ms | 粒密度が上がり、個々の音が溶けて「バリバリ」「ザザザ」に | **最後のアクセント**（バシャッ／ザッ！）＋崩落音 |
| 洪水 | 26〜 | 300〜450ms | 連続した質感の流れ（殻が割れる音の洪水／粒の雪崩） | アクセント＋長い崩落と余韻（数に応じて対数で伸ばす）＋柔らかい解放の空気感 |

3. ラウドネスは √N 程度までに抑える。規模感は **長さ・密度・ステレオの広がり・最後のアクセント・余韻の長さ** で出す。
4. 素材が混ざっている場合は、波の中でそれぞれの素材の音を鳴らし、崩落音は撃破数の多い素材を優先する。

## 4. 評価の観点
- コマ送り画像で、波が刃の進行方向に沿って転がっていくのが見えるか。
- 波形とスペクトログラムで、段階ごとに質感（トランジェントの密度、帯域、長さ）が変わっているか。単に音量が変わっているだけになっていないか。
- 予兆の長さを素材ごとに計測し、プロファイルどおりになっているか。
- 人間の耳で、40体を倒したとき「洪水」「雪崩」に聞こえ、耳が疲れないか。
