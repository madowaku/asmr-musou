# v0.3 方向性（正本）— 2026-11-22 人間の決定を反映

## 最終目標
癒やし系のタップゲームではなく、**ASMR素材の敵をバッサバッサ倒していく、圧倒的に気持ちいいストレス解消アクション**。

## 人間が決めたこと
- **無双モードが本編の主軸**。v0.2 の癒やし系体験は、別モードとして残す候補。
- **雑魚は大量に高速処理し、ボスで素材の破壊をじっくり味わう**。
- 敵は擬人化してよい。ただし**キャラクター性より素材感を優先**する（顔は小さく控えめに。素材の質感・断面・壊れ方が主役）。
- 技術選定は総監督に任せる。既存実装を守ることより、最終的な体験の質を優先する。**追加費用のかかるサービスは事前に人間へ相談**する。
- 失敗した手法や不採用案も、研究記録として残す。

## 研究所（lab.html）の重点研究
1. 指で斬った軌跡どおりに物体が切断される快感
2. 素材ごとに異なる変形・亀裂・断面・破片・崩落
3. 硬い外殻と柔らかい内部の対比
4. 一振りで大量の敵を倒す無双感
5. 大量破壊時にも耳障りにならないASMR音響
6. 破壊の瞬間が短い動画でも魅力的に伝わる演出

## 研究対象の素材
ロウ、ゼリー、石鹸、砂、吸水スポンジ、チョーク、粒入りスライム、琥珀糖

## 評価基準
「実装できたか」ではなく「その素材特有の気持ちよさを表現できたか」で評価する。評価は総監督（Opus 5.5）が、33msのコマ送り画像、動画、指標、実際の操作で行う。

## 技術方針（総監督の初期決定。研究の結果で覆してよい）
- 描画は **WebGL2**（ライブラリなし）。理由：砂の数千粒、群れ、切断面とつやのシェーダーを Canvas 2D ではまかないきれないため。
- 切断は2Dの幾何で行う：凹多角形を線で分割し、耳切り法で三角形分割する。テクスチャ座標は元のスプライト空間のままにして、断面には専用シェーダーで帯状の面を描く。
- 柔らかい素材は形状マッチング法の軟体、粒は CPU で計算してインスタンス描画する。
- file:// のまま WebGL で画像を使えないため、`tools/bundle-lab-assets.cjs` で画像を base64 の JS に埋め込む。http サーバー経由でも動くようにする。
- モバイル目標：CPU を4倍スロットルした状態で p95 < 8ms（v0.2 と同じゲート）。
