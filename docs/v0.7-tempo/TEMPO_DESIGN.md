# ASMR MUSOU：CRUNCH LINE v0.7 TEMPO — 序盤の出現と連続攻撃の比較版（総監督）

試遊ページ：`tempo.html`（v0.7 の `crunch.html` は比較のため、同じビルドにそのまま残す）

## 0. 出発点（v0.7 の人間による試遊結果）
- 敵が少なくなったことで、**序盤が暇になった**。
- 意図していたのは「敵の数を減らして操作も減らす」ことではない。**序盤も終盤も攻撃の頻度は大きく変えず、一回の攻撃で壊せる量が成長で増える**構成にしたい。

## 1. 中心の考え
> 指はずっと同じリズムで動いている。変わるのは、一回で壊れる量。
> 序盤：一体を2〜4回 → 成長：一回で一体 → 大群：一回で群れごと。

## 2. 変えたこと（v0.7 からの差分だけ。操作・音・強化・ボス・防衛ラインは同じ）
| 依頼 | 変えたこと |
|---|---|
| 1. 序盤は常に2〜4体を攻撃できる位置に | 開幕の3体を、画面の上から下りてくる途中ではなく、最初から届く位置（y=230〜470）に置く。届く位置の敵が3体未満になったら0.5秒で、2体未満になったら即座に、届く位置へ新しい敵が**ポンと現れる**（輪が広がり、素材の音が鳴る）。上限4体 |
| 2. 一体に2〜4回、一撃ごとに形・断面・音がはっきり変わる | v0.7 の「切り落とし・中身の帯・亀裂」に加え、**一撃ごとに高くなるひびの音**（ピキッ → ピキキッ → パキン）を足した。必要な回数は v0.7 と同じ（大剣士・魔法使い3回、拳闘士2回） |
| 3. 同じ敵を続けて斬る・殴る。飛びすぎない、追撃が途切れない | 拳闘士の倒しきれない一撃は、敵を**30px だけ押し戻す**（ぶっ飛ばし強化で60px）。v0.7 は約150px 飛ばしていた。大剣士・魔法使いは、もともと本体がほとんど動かない |
| 4. 12秒以降、最初の敵は一撃 | v0.7 と同じ（威力 1 → 3） |
| 5. 終盤は頻度を増やさず、一撃で大量に | 12秒以降も「届く位置の敵」が減ったら補充する（成長の時間は7体未満で群れを、大群の時間は16体未満で大群を、手前に出す）。**大群は画面の中ほどで約2.2秒かたまって止まってから**押し寄せる（まとめて叩ける瞬間を作る） |
| 6. 大群・ボス・防衛ラインは維持 | 変えていない |
| （見つけた不具合） | 何度も削ったゼリーを砕くと、三角形に分割できない形ができてページが止まることがあった（v0.7 にもある）。TEMPO では、切断が失敗したらその場で粉になって消え、撃破として数える |

## 3. 計測（依頼の4指標を段階別に）
`node tests/tempo/compare.mjs`。v0.7 と TEMPO を、**同じ外部ボット**が実際の入力の通り道で遊ぶ。

- ボットは「選んだ敵が壊れるまで叩き続ける」人の代わり。ラインに近い敵を先に、なければ群れの濃い所を狙う。敵の位置は**0.25秒前の位置**を見て狙う（人の反応の遅れ）。
- 届く敵がいないときは、何もせずに待つ。**入力の回数を揃えようとはしない**（待った時間がそのまま「敵を待っている時間」になる）。
- テンポは2通り：連打（約0.42秒ごと）と、のんびり（約0.8秒ごと）。

| 指標 | 意味 |
|---|---|
| 操作回数 | 1秒あたりの攻撃の数 |
| 敵を待っている時間 | 届く位置（画面のHUDより下〜ラインより上、飛んでいない）に敵が1体もいない時間の割合 |
| 一体への連続攻撃 | 直前と同じ敵を狙った攻撃が、0.6秒以内にその敵に当たった割合。同じ敵に続けて当たった最長の回数。開幕の一体を壊すのに当たった回数 |
| 一撃あたりの撃破数 | 段階ごとの「撃破数 ÷ 攻撃数」 |

加えて、実際のタッチで「同じ場所を4回連打」して、当たった回数と、一撃ごとに敵が動いた距離を測った（`node tests/tempo/mash.mjs`）。
