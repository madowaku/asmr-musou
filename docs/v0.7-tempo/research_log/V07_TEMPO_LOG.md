# v0.7 TEMPO — 研究記録（総監督）

設計は [TEMPO_DESIGN.md](../TEMPO_DESIGN.md)、人間の評価は [PLAYTEST_TEMPO.md](../PLAYTEST_TEMPO.md)（未検証）。元データ：`research/v07t/compare.json`・`mash.json`・`perf.txt`。

## 1. 段階別の4指標（v0.7 → TEMPO、4戦場 × 3キャラ、同じ外部ボット）
連打のテンポ（約0.42秒ごとに攻撃を試みる）の結果。のんびり（約0.8秒ごと）も同じ傾向（compare.txt）。

| 段階 | 指標 | 大剣士 | 拳闘士 | 魔法使い |
|---|---|---|---|---|
| 開幕（0〜12秒） | 1秒あたりの操作 | 1.36 → **2.05** | 1.18 → **2.36** | 1.39 → **2.36** |
| | 敵を待っている時間 | 49% → **0%** | 75% → **0%** | 57% → **0%** |
| | 届く位置にいる敵 | 0.7 → 2.8体 | 0.3 → 2.8体 | 0.6 → 2.7体 |
| | 一体を壊すのに当たった回数 | 3.0 → 3.0 | 2.9 → 2.4 | 3.0 → 3.0 |
| | 同じ敵への追撃が当たった割合 | 100% → 100% | 100% → 100% | 100% → 100% |
| | 一撃あたりの撃破 | 0.61 → 0.75 | 0.69 → 0.67 | 0.60 → 0.62 |
| 成長（12〜24秒） | 1秒あたりの操作 | 0.54 → 1.54 | 1.11 → 2.24 | 0.43 → 1.76 |
| | 敵を待っている時間 | 91% → 33% | 79% → 3% | 97% → 37% |
| | 一撃あたりの撃破 | 4.7 → 36.1 | 2.0 → 19.5 | 6.3 → 31.3 |
| 大群（24〜40秒） | 1秒あたりの操作 | 0.80 → 1.53 | 1.62 → 2.30 | 0.70 → 1.77 |
| | 敵を待っている時間 | 86% → 58% | 55% → 3% | 91% → 57% |
| | 一撃あたりの撃破 | 28.6 → 28.9 | 14.8 → 18.1 | 34.8 → 26.6 |
| ボス | 撃破・時間 | 4/4 6.8秒 → 4/4 5.5秒 | 4/4 8.1秒 → 4/4 12.2秒 | 4/4 9.6秒 → 4/4 6.8秒 |
| 全体 | 侵入 | 0 → 0 | 0 → 0 | 0 → 0 |

読み取り：
- **序盤の暇は解消した**：待ち時間 49〜75% → 0%。届く位置に常に約3体いて、操作は1秒に約2回。一体に約3回（拳闘士は2〜3回）当てて壊れる。
- **一撃で壊せる量は、成長で増える**：一撃あたりの撃破は、開幕 0.6〜0.75 → 成長後 19〜36 → 大群 18〜29。操作の頻度は、拳闘士では全段階で約2.3回/秒とほぼ一定。
- **大剣士と魔法使いは、12秒以降もまだ待ちが残る**（33〜58%）。一撃で届く範囲の敵がまとめて消え、補充（上から入ってくる群れ）が追いつかない。性能のため補充に上限を設けたことで、大群の時間の待ちは 42% → 57〜58% に増えた。
- **追撃の命中は、ボットでは差が出なかった**（両方 100%）。ボットは敵の位置を追って狙い直すため（拳闘士の殴りは300px以内の一番近い敵へ自動で向かう）。差は「敵が動く距離」に表れる（§2）。

## 2. 同じ場所を連打する実タッチ（`tests/tempo/mash.mjs`）
開幕の敵1体に、指を動かさずに0.35秒おきに4回タッチ（大剣士は同じ線を4回なぞる）。

| | 当たった回数 | 一撃ごとに敵が動いた距離 |
|---|---|---|
| v0.7 大剣士 / 拳闘士 / 魔法使い | 3 / 2 / 3（1体を壊して終わり。あとは空振り） | 18〜25 / 8〜130 / 10〜18 px |
| TEMPO 大剣士 / 拳闘士 / 魔法使い | 7 / 8 / 3 | 16〜24 / 1〜70 / 14〜16 px |

- TEMPO では、1体を壊すとすぐ届く位置に次の敵が現れるので、同じ場所の連打が空振りしにくい（大剣士・拳闘士）。
- v0.7 の拳闘士は、とどめの殴りで敵が約130px 動いた。TEMPO の押し戻しは約30px（ぶっ飛ばし強化で60px）。

## 3. 性能（CPU 4倍、音あり、フレーム p95）
| | 開幕 | 大群 | ボス |
|---|---|---|---|
| v0.7 | 4.0〜4.6ms | 7.1〜9.6ms | 7.6〜9.0ms |
| TEMPO | 4.3〜5.3ms | **11.7〜15.0ms** | 7.9〜11.1ms |

大群の時間は、補充で体と破片が増えるため重くなった（v0.6 の大群 11.7〜15.5ms と同程度）。60fps の予算（16.7ms）には収まる。Android 実機は未計測。

## 4. 失敗と直し方
| 何が起きたか | 原因 | 直し方 |
|---|---|---|
| 開幕を直しても、12秒以降は 74〜97% の時間、敵を待っていた | 成長後は一撃で群れが消え、次の群れは画面の外から歩いてくる | 届く位置の敵が少なくなったら、群れ・大群を手前に出す |
| 自動の比較が途中で止まった | 何度も削ったゼリーを砕くとき、三角形に分割できない形ができて例外になった。**v0.7 にもある不具合** | TEMPO では、切断が失敗したらその場で粉になって消え、撃破として数える。v0.7（保護対象）は直さず、計測のときだけ外から同じ保護を当てた |
| 大群の時間のフレームが 13〜16ms に | 補充で体と破片が上限（230）に張り付いた | 体と破片が170未満のときだけ補充し、敵の上限を80→64に。11.7〜15ms に下がったが、待ち時間は増えた |
| 実タッチの連打テストで、ボットの追撃の差が出ない | ボットは敵を追って狙い直す。拳闘士の殴りも、近くの敵へ自動で向かう | 「指を動かさずに連打」する実タッチのテストを足し、当たった回数と、敵が動いた距離で比べた |

## 5. 人間が確かめるまで分からないこと（未検証）
- 序盤に「自然に連打したくなる」か。一撃ごとの変化（削れ・断面・高くなるひびの音）が、連打の手応えになっているか。
- 新しい敵が「ポンと現れる」のは不自然ではないか（上から歩いてくる方がよいか）。
- 大群が画面の中ほどで一度止まるのは、気持ちよいか、不自然か。
- 拳闘士の押し戻し（30px）は、手応えとして弱すぎないか。

## 6. 次の仮説
1. 大剣士・魔法使いの12秒以降の待ちを減らすには、敵の数ではなく「横に広い隊形」（一撃で届く範囲の外にも敵がいる形）にする。
2. 大群の時間の重さは、破片の寿命を短くすれば、補充を減らさずに下げられる。
3. 拳闘士のボス（12秒前後）は、殴り1発の手応えを v0.5 の3回分から4回分に増やす。
