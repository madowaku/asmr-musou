# ASMR MUSOU：COMBAT LAB v0.4 — 設計仮説（総監督）

出発点は人間の試遊結果：「素材を壊すこと自体は気持ちいいが、ゲーム性が弱く、中毒性がない」。
目標は「適当でも気持ちいい／少し考えるともっと気持ちいい／上手いととんでもなく気持ちいい／失敗してもストレスにならない／自分の判断で快感を生んだ実感がある」。

## 1. 中心となる仮説
> **一手で何体を巻き込めたか、が快感の大きさになる。** その一手は、キャラクターの体の動きとして画面に現れる。

- v0.3 で作った「撃破数が増えるほど音の質感が変わる」（パキッ→バリバリ→洪水）を、そのまま**報酬の大きさ**として使う。点数より先に、耳と目が「今のは上手かった」と教える。
- 「考える」余地は、**陣形の読み**（どこから入れば一筆で多く巻き込めるか）と、**素材の相性**（硬い殻と柔らかい中身、導電、脆さ）に置く。
- 失敗のコストを作らない：体力も残機もない。ミスは「今回は少なかった」だけ。陣形は画面外へ抜けていくだけで、罰はない。

## 2. 操作の文法（3キャラ共通、片手・縦画面）
親指は画面下半分に置いたまま、**キャラクターを基準にした相対操作**にする（敵を直接タップして消すのではなく、キャラクターの体が動いて壊す）。

| 入力 | 意味 | 狙い |
|---|---|---|
| **フリック／スワイプ** | 描いた軌跡の形のまま、キャラクターが自分の位置から突進する（長さは約1.6倍に拡大）。曲線を描けば曲がって突進する | 適当に振っても気持ちいい。移動と攻撃が同じ一つの動作 |
| **長押し→引いて→離す（スリングショット）** | 溜めて狙う大技。引いた方向の逆へ放つ。照準線と予測を表示 | 少し考えると、もっと気持ちいい |
| **タップ** | その場での小技（近くの敵を自動で狙う補助） | 操作の負担を下げる。完全自動ではない |

参考にした操作設計：Fruit Ninja（スワイプで切る即時性）、Archero（片手で移動）、Angry Birds（スリングショットの予測と連鎖）、Peggle（仕掛けて見守る連鎖の快感）。

## 3. 3キャラクターの違い（攻撃力ではなく、戦い方の違い）
| | SLASHER 大剣士 | CRUSHER 拳闘士 | CASTER 魔法使い |
|---|---|---|---|
| 一言 | 斬り抜ける | 殴り飛ばして当てる | 仕掛けて広げる |
| フリック | 軌跡に沿って突進斬り。剣の幅が広く、通り道の敵を全部一刀両断 | 突進して最初の敵を殴り飛ばす。飛んだ敵が**弾**になり、当たった敵を壊す（連鎖） | 軌跡に沿って風を起こし、敵を押し流す（壊さない。次の魔法の仕込み） |
| スリングショット | 溜め突進斬り：長く・硬い素材も斬れる | 溜めパンチ：狙った方向に強く飛ばす弾。硬い弾は柔らかい敵を貫通していく | 重力球：置いた地点に敵を吸い寄せ、圧縮して一斉に潰す（集めた数が多いほど大爆縮） |
| タップ | 回転斬り（周囲を一周） | 地面打ち（周囲の敵をへこませ、ひびを入れる） | 落雷：近い敵に落ち、**導電する素材（ゼリー、スライム、スポンジ、石鹸）を伝って連鎖**する |
| 苦手 | 硬い素材は1回では斬れず、弾かれる（溜めると斬れる） | 柔らかい弾は硬い敵を壊せない | 乾いた素材（砂、チョーク）は雷を通さない |
| 得意素材 | 石鹸、ゼリー、琥珀糖 | ロウ、チョーク、（硬い弾） | 砂、琥珀糖（氷の代用）、粒入りスライム |
| 音の体験 | 一筆の中で、撃破ごとに音階が上がるシュッ・シュッ・シュッ | 重いドン、反動、弾が当たるたびのバキッ（連鎖の数え上げ） | 仕込みの静けさ（吸い込み・雷の予兆）→ 一斉に弾ける解放 |

## 4. 陣形＝小さな問題（5種）
どれも「正解の一手」を強制しない。上手い判断ほど、一手あたりの撃破数が増える。
1. **密集**：一筆で多数を巻き込める。SLASHER の基本形。CASTER の重力球でも大きく取れる。
2. **縦列**：縦の一直線。縦に斬り抜けるか、先頭を殴って後ろへ玉突きさせる（CRUSHER の見せ場）。
3. **包囲**：キャラクターの周りを囲む輪。回転斬り、地面打ち、雷の連鎖のどれでも解ける。
4. **硬が柔を守る**：硬い殻（琥珀糖、チョーク）の輪が、柔らかい中身（ゼリー、スライム）を守る。溜め斬り、硬い弾を撃ち込む、殻ごと重力で潰す、のいずれか。
5. **混成**：導電する素材と乾いた素材が混ざる。雷が通る道筋を読む、乾いたものを弾にして導電する列へ撃ち込む、など。

陣形ごとに「この数の手で全部倒せたら上出来」という目安の手数（par）を薄く表示する。par 以内で全滅させると PERFECT（音と光の小さなご褒美）。罰はない。

## 5. 60秒の時間構造（緩急）
`雑魚ラッシュ（陣形×5、約35秒）→ 巨大素材ボス（約18秒）→ 大規模破壊 → 余韻（約4秒）→ 結果（即リトライ／キャラ切替）`
- 雑魚：速く、たくさん。一手で波のように壊れる（破断の波）。
- ボス：多層構造。外殻（琥珀糖＝硬い）→ 中層（石鹸＝斬りやすい）→ 核（粒入りスライム＝柔らかい）。層ごとに得意なキャラが違うが、どのキャラでも倒せる。予兆を長くとり、じっくり壊す。
- 大規模破壊：核が崩れると、ボスの破片が残っている雑魚を巻き込んで崩落する（連鎖）。スローと共に。
- 余韻：砂の山、粉、しずく。静かな音だけが残る。
- 同じ乱数シードで、キャラを切り替えて同じ条件を比べられる。

## 6. 検証の方針（AIの客観検証と人間の主観評価を分ける）
- **AI の客観検証**：自動プレイヤー（ボット）を3つの腕前（でたらめ、素朴、上手い）で各キャラに動かし、同じシードで陣形ごとの「一手あたり撃破数」「連鎖の発生数と最大長」「PERFECT 率」「60秒の総撃破数」を測る。設計の狙い（上手いほど一手あたりの撃破数が増える、キャラごとに得意な陣形が違う、連鎖が狙って起こせる）が数字に出るかを見る。
- **人間の主観評価**：試遊ガイドで「意図した攻撃を出せるか」「キャラの違い」「陣形を読む意味」「連鎖を狙えるか」「大量撃破が単体より気持ちいいか」「単調でないか」「もう一回遊びたいか」を記録する。
- 失敗した試作、捨てた仮説、技術の選択とその理由は `docs/v0.4/research_log/` に残す。
