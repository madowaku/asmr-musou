## 仕上げの判断

- 大剣士は踏み込みと振り抜き、拳闘士は打撃直後の反動、魔法使いは浮き上がりと緩やかな着地、双剣士は交互に傾く切り返し、圧延士は足元を低く保つ荷重で区別します。実際の攻撃開始と成長確定から描画用の動きを始めます。巨大素材を壊した直後は各自の勝利の動き、結果画面では選んだキャラクターの立ち絵を出します。姿勢は描画座標にだけ適用し、入力・当たり判定の座標を変えません。
- 居合は無双時の長い先頭列を9体に、玉突きは隊形フェーズで同じ縦軸に6体、圧延は重なりすぎない密集列にしました。素材ごとの初動サイズと列のシルエットを比較し、石鹸は狙いやすい手前の空き位置を先に探します。敵のHP、攻撃の間隔、ボス登場時刻は既存の値を使います。
- タイトルはロウの工房の写真札を再利用し、丸い縁と金の線を世界選択・戦闘・結果につなげました。図鑑の無地は資料撮影用として維持しています。
- 撮影中は右上の小さなボタンから、フィールドだけを静止して確認できます。書き出し範囲は戦場のキャンバスで、操作ボタンは写りません。保存はブラウザのローカルダウンロードです。

## 検証

`tests/studio/roller-feel.mjs` の失敗は、圧延の改良が標準機能になった後も、テストがオプトイン時代の「通常起動時は未定義」「練習は3素材」を期待していたことが原因です。通常起動、8素材の練習入口、旧比較の無効化を個別に確認し、実際の圧縮、切り返し、残留物の再加工、5段階の圧延と幅拡張の検証を引き継ぎました。

`tests/studio/v10-verify.mjs` の同じ自動操作で、公開版・仕上げ版ともに全8ステージをクリアしました。下表は、攻略中に y=400 以降の通常敵と有効なボス片がいずれも見つからなかったフレームの割合です。人による狙いやすさの評定とは別に扱います。
