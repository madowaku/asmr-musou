# ASMR MUSOU：CRUNCH LINE v0.7 — 縦スクロール防衛 × 成長 × 素材破壊（総監督）

試遊ページ：`crunch.html`（v0.6 の `stages.html`、v0.5 の `feel.html` は比較のためそのまま残す）

> **一つを味わう。やがて、全部を砕く。**

## 0. 出発点（v0.6 の人間による試遊結果）
- 音も操作も気持ちよくなった。
- **開幕から大量の敵が出るので、一体ずつ壊す過程を味わう余裕がない。**
- 最初は少数の敵を何回か攻撃して壊し、成長したら昔の敵を一撃で大量に倒したい。そこへ新しい強い敵が現れ、また何度も叩く楽しさが戻る。

## 1. ルール
- 敵は画面の上からゆっくり下りてくる。画面下の**防衛ライン**（y=1100、ピンクとミントの縞）を越えると「侵入」として記録する。
- **ゲームオーバーはない。** 60秒間、最後まで遊べる。侵入ゼロで終えると、結果画面に **PERFECT DEFENSE** が出る。
- 操作は v0.5〜v0.6 と同じ（`feel/heroes.js` を共有）。指が場所を決め、キャラが自分でそこへ踏み込む。移動の操作は増やしていない。キャラは攻撃のあと、ラインのすぐ上へ戻る。

## 2. 敵の壊れ方：HP ではなく、削れていく姿で見せる
敵は何回か叩かないと壊れない。**倒しきれない一撃でも、必ず形・見た目・音が変わる。**

| 一撃ごとに起きること | 実装 |
|---|---|
| 変形 | 叩かれた側から、本体の約2〜3割が実際に**切り落とされて**飛ぶ（v0.3 の切断エンジン）。残りが敵として残り、だんだん小さく、いびつになる |
| 内部露出 | 切り落とした破片の断面が開く（v0.3 の「本が開く」断面）。残った本体の切り口には、その素材の中身の色の帯が残り続ける（ロウ＝クリーム、ゼリー＝淡い紫、琥珀糖＝淡い金色） |
| 亀裂 | 切り口から内側へ、暗い亀裂が2〜3本伸びる。本体と一緒に回る |
| 手応え | 一瞬つぶれる（スクワッシュ）、素材の色の粒が散る |
| 音 | その素材の切断音・打撃音・崩れる粒の音（v0.3 の素材音） |

- HP の棒や数字は出さない（ボスの層だけは、v0.5 から続く小さな印が残る）。
- **成長＝威力**：強化を選ぶたびに、一撃の威力が 1 → 3 → 5 になる。v0.5 の強化（形・音・壊れ方が変わる）はそのまま加わる。強化の画面に「どちらを選んでも 威力 1 → 3：最初の敵が一撃で壊れる」と出す。

## 3. 敵の種類
| 種類 | 素材 | 大きさ（半径） | 必要な打数（威力1換算） | 速さ | 出る時間 |
|---|---|---|---|---|---|
| ふつう（開幕の敵） | ロウ・ゼリー | 80〜90（大きく見せる） | 3 | 30 px/秒 | 0〜24秒 |
| 群れ | ロウ・ゼリー・石鹸 | 38〜44 | 3 | 62 | 12〜24秒 |
| 大群 | ゼリー・石鹸・ロウ・粒入りスライム | 27〜32 | 2 | 84 | 24秒〜 |
| 硬い新型 | 琥珀糖 | 70〜76 | 15（威力5で3打） | 32 | 24〜40秒 |
| 巨大素材ボス | 琥珀糖の殻 → 石鹸 → 粒入りスライムの核 | — | 外殻5・中層3・核12（一撃1） | 下りてくる | 40秒〜 |

- 「少数戦では素材を大きく、無双では群れを広く」は、カメラのズームではなく**敵の大きさ**で表した（開幕は半径80〜90の大きな敵、大群は27〜32の小さな敵が画面いっぱい）。座標が指と一致したままで、費用もかからない。

## 4. 60秒の流れ
| 時間 | 内容 | 威力 |
|---|---|---|
| 0〜12秒 | 大きな敵が3体。壊すたびに補充（最大4体）。一体を3回ほど叩いて、じっくり壊す | 1 |
| 12秒 | 強化 1/2（時間停止） | → 3 |
| 12〜24秒 | 群れ（5体ずつ）が下りてくる。最初の敵も群れも**一撃**で壊れる | 3 |
| 24秒 | 強化 2/2 | → 5 |
| 24〜40秒 | 「大群」の合図とともに、密集した大群が一度に押し寄せ、続けて流れてくる。**硬い新型（琥珀糖）**が4.5秒ごとに混ざり、また3回叩いて砕く | 5 |
| 40秒〜 | 巨大素材ボスが上から下りてくる（ラインには届かない）。周りの雑魚は少なめ | 5 |
| 撃破時 | スローの大崩落 → 余韻（約4秒）→ 結果。56秒で倒せなくても自分から崩れる | |

依頼書の仮案（大群 24〜44秒、ボス 44秒〜）から、人間に近いテンポのボットでもボスまで届くように、ボスを40秒に早めた。

## 5. 画面（カラフルポップな ASMR スタジオ）
- クリーム色からピンクへのグラデーションの床。床の線は画面の上の一点に向かって狭まり、斜め上から見下ろした（70°風の）奥行きを出す。**描画は2Dのままなので、触った場所と攻撃の場所は1:1で一致する。**
- 画面下にピンクとミントの縞の防衛ライン。侵入されるとラインが光り、HUD の「侵入」の数字が弾む。
- ラインに近づいた敵（ラインの250px手前から）の足元に、点滅するピンクの影を出す（次に届く敵が自然に目に入るように）。
- HUD は最小限：時間・撃破数・侵入数・次の強化までの目盛り・取った強化。
- 暗い画面向けだった白っぽい効果（刃の軌跡・魔法の輪）は、明るい背景で消えないように、色味を保ったまま濃くした。加算の光は弱めた。描画エンジン（v0.3）は変えていない。

## 6. キャラの役割
| キャラ | v0.7 での役割 |
|---|---|
| 大剣士 | 横に長い斬撃で、並んで下りてくる群れをまとめて切る（操作は v0.5 と同じ） |
| 拳闘士 | 倒しきれない一撃は敵を削って**後ろへ押し返し**、押し返された敵が後ろの群れにぶつかる。とどめの一撃は、後ろに群れがいれば v0.5 の玉突き（殴り飛ばす）、いなければその場で砕けて破片を後ろへ飛ばす |
| 魔法使い | 範囲の破壊。長押しで吸い込んで一斉に粉砕（v0.5 と同じ） |

## 7. やめたこと・変えたこと
| 変えたもの | 理由 |
|---|---|
| チョークの「硬い殻」ルール（v0.4〜） | すべての攻撃を同じ「削れる」仕組みに通すため |
| 殴り飛ばした敵が画面上端で跳ね返る（v0.5） | 群れのいない場所では、跳ね返った敵がそのまま落ちてラインを越えていた。下向きに転じた時点で砕けるようにした |
| v0.6 のステージ進行・素材の紹介・図鑑 | 今回の研究（縦スクロール防衛で面白くなるか）に絞るため、`crunch.html` には入れていない。`stages.html` は残っている |
