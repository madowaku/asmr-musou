# 大剣士の居合斬り

[居合の試遊入口](../../studio/iai.html) をChromeで開き、「居合の練習」からロウ、ゼリー、石鹸を選ぶ。複数配置は一振りで断面を見比べられる薄い素材。横にスワイプすると、剣士が抜けた後、細い線だけが残る。少し置いて、その線に沿って素材の左右の断面が順に開く。ロウでは殻と芯が見えやすい。

ステージ攻略は通常の耐久、成長、ボス条件を使い、タップと長押しは従来の回転斬り。居合の試遊の進行は現行版と別に保存する。双剣士の吸い込み旋風と ROLLER の研究版は比較用に残す。

短い抜刀音と既存の素材別合成音は、断面の開くタイミングに合わせて鳴らす。共有のCC0音素材も確認したが、今回の音はゲーム内の既存合成を使用。

`node tests/studio/iai.mjs <画像保存先>` でChromeのタッチ入力と順番を検証。素材2個で初回入力から0.250秒と0.367秒に破断し、断面がそれぞれ2面生成された。居合だけでStage 1をクリアする経路も確認した。実機の操作感、静寂の長さと音の好みは未検証。

初期の `GAME_DIRECTION.md` は濃紺・45秒。今回の研究は v0.9 Studio の明るい工房・60秒を基準にした。
