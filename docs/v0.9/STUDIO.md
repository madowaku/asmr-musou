# CRUNCH STUDIO v0.9

このページは v0.9 の試作時点の記録です。現行 Studio の時間配分・素材数・ROLLER の動作は [WORLD ATELIER 仕上げ・現行仕様](../v1.3/STUDIO_CURRENT.md) を参照してください。

- 開くページは [studio.html](../../studio.html)。ローカルは Chrome で直接開ける。HTTPS は v0.9 専用プレビューの `/studio`。
- 本編のステージは60秒制。ボス撃破でクリア、次のステージとその素材が解放される。侵入は記録し、ゲームオーバー条件にはしない。
- ASMR図鑑はクリア済み素材を選び、5人からキャラクターを選ぶ。単体・6個配置・片付けるたびに6個補充の3通り。時間制限、侵入、成長はなし。「素材を置き直す」でやり直せる。
- 記録、キャラクター選択、音、画面の揺れ設定はブラウザ内の `asmr-crunch-studio-v09` に保存する。

## 設計の選択

`GAME_DIRECTION.md` にある45秒・濃紺は初期版の条件。Studio は今回の指示とv0.8/v0.6の設計を基準に、60秒・3素材の明るい工房とした。既存の研究版は独立した入口として維持する。

- ROLLER の押し込みは、指の移動速度、接触時間、横幅で決まる。蓄積した圧縮は折り返し後も残る。接触中の敵を一時的に遅らせ、タップ連打を前提とせず一体を仕留められるようにした。
- SPINNER は v0.8 の円認識、切断、吸い込みを使用。Studio では初回の2択に「吸い込み旋風」を入れた。
- 開幕は主役素材の大きな3体。大剣・魔法・拳では奥に次の素材が見える行列を維持し、ROLLER では圧延の折り返しや縦移動が次の敵につながるよう開幕の列を中央に寄せた。成長後は群れの破壊に切り替わる。
- ロウ、ゼリー、石鹸それぞれに背景・ボス・素材音のミックスを設定。ステージ中盤から、過去の素材をまとまりで混ぜる。ボスは素材層が外から順に壊れ、制限時間切れは未クリアの結果になる。
- 削れた面積、圧縮の節目、撃破で CRUNCH ENERGY が増える。破片から分かれた光がゲージへ飛び、強化後は攻撃の色や範囲が変わる。

## 検証

`node tests/studio/play.mjs` は390×780のChromeで通常ページのタッチと一時停止を試し、同じ入力ハンドラを使った加速試験で3ステージ攻略、時間切れでの解放禁止、図鑑解放と再読み込み、3配置、連続供給、5人を確認する。第1引数に保存先を渡すと画面を記録する。配信先を確認するときは `STUDIO_PREVIEW_URL` にページURLを設定する。

スマートフォン実機の速度・音量・指の疲れ、ステージの難しさ、5人の使い分けや繰り返し遊びたくなるかは人間による試遊項目。ブラウザのテストでは代用しない。
