# Phase B — ROLLER 試験台

Chrome でリポジトリ直下の [roller.html](../../roller.html) を開く。スマホでの比較は HTTPS または同じ Wi-Fi の静的サーバーからこのファイルを開く。試験台には制限時間・侵入・成長がない。`flow.html` から独立しており、Cloudflare Pages では v0.9 ブランチのプレビューから開ける。

## 同じ素材で比べる

1. 「音を鳴らす」を押す。ロウを真ん中から上下に、速く1往復する。
2. 「もう一度」でロウを入れ替え、同じ距離をゆっくり往復させる。殻、芯、ぺたんこの状態まで、変形と音がつながるか確かめる。
3. 「＋長押し」に切り替えて同じロウを置き、真ん中で指を止める。転がす操作と比べ、どちらを繰り返したくなったか確認する。
4. 「連続圧延」で、同じ素材が2列×3段。指を離さず片方の列を下り、横へ渡ってもう片方を上がる。小さい素材は単体モードより早く潰れるので、連続する音と動きに注目する。
5. ゼリーと石鹸で繰り返す。ゼリーは横に広がって弾ける。石鹸は細い跡が増え、薄片にほぐれる。

## 実装と出典

- 低速の転がしを圧縮に変換し、接触中のへこみと蓄積した変形を別々に描く。折り返しても圧縮は残る。「＋長押し」では比較用に停止中の圧縮を有効にする。圧力センサー不要。
- v0.3 素材研究所の WebGL2 描画、バンドル済みの `body/*_boss`・`xsec/*`・破片アトラス、`lab/audio/` の合成音を再利用。台とツールは試験場用に描画。共有アセットの音源フォルダは所在のみ確認し、素材ファイルは追加していない。添付2枚は色、艶、形の方向性の参考。
- Chrome の既存テスト環境で `node tests/roller/bench.mjs`。720×1280 座標の同距離比較、タッチ入力、キーボード、リセット、Web Audio の動作を確認する。音質・快感・端末性能は上の試遊で評価する。

## Phase B の計測結果

同距離360ワールドpxの横断を比較したモデルテスト。160px/秒と1100px/秒で、終了時の圧縮率はロウ89%／1%、ゼリー100%／2%、石鹸82%／1%（四捨五入）。速度は試験用の設定値。

Chrome の390×780タッチエミュレーションでは、3素材とも最終状態まで到達。停止圧縮の有無、タッチキャンセル、素材の入れ替え、音の開始とミュート、PCのキーボード、幅320pxのコントロール、FLOWへの遷移を確認。ブラウザエラー0。

既存の `npm test` も合格。標準試験のCPU 4倍制限で更新・描画のp95は6ms（v0.2 の性能試験。GPU描画やROLLER、Androidの実機性能は計測対象外）。
