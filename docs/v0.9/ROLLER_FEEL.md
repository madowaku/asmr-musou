# ROLLER 手触り研究

## 比べ方

- 現行の基準版は v0.9 の `ebf54f1`。既存 URL の通常モードでも、同じ ROLLER 操作を選べる。
- 改善版は [studio.html?roller=feel](../../studio.html?roller=feel)。タイトルの「ROLLERの練習」から、素材解放前でもロウ・ゼリー・石鹸を単体・複数・連続供給で試せる。「ステージ攻略」では同じ改良を60秒防衛で試せる。進行と設定は基準版と別に保存する。
- 人間の試遊では SPINNER の吸い込み旋風が評価された。円認識・吸い寄せ・切断は変更せず、連続する素材ごとの反応を ROLLER の比較基準にした。

## 試す順番

1. **止め押し**。ロウに指を置き、最初のパキッとした音・へこみから、殻と芯が見えるまでの間を聴く。
2. **ゆっくり圧延**。同じロウを横切り、残った押し跡で折り返す。途中で指を離し、へこみと芯が残ることも確かめる。
3. **ひと転がし**。石鹸を複数置き、列に沿って少し速く動かす。薄い削りかすと前から素材が寄る動きを見る。戻して残りを崩す。
4. **防衛**。成長でヘッドが横に広がった後、隣の列も一続きに圧延できるかを試す。

## 実装と計測

速度に応じて深さと巻き込みを配分する。最初の接触でへこみ・短音・反応線、深さに応じて亀裂・薄片・断面を出し、圧縮中の音は止め押し・低速・高速で変える。潰した跡は折り返しや次のストロークで再圧延できる。跡を砕いても撃破数や経験値は増えない。

`node tests/studio/roller-feel.mjs` で初回タッチ、素材音、折り返し、巻き込み、成長後の複数破壊を確認。ロウへの指定入力では、同じ距離を横切る試験では、ゆっくりした通過で圧縮100%、速い通過で約10%、0.5秒の止め押しで約43%。成長試験のヘッド幅は開始時114→最大382ワールドpx（ワイドローラー込み）。これらは計測用の入力・構成での結果。Android・iOS 実機の操作感、音の印象、吸い込み旋風と比べた楽しさは未判定。

`GAME_DIRECTION.md` の45秒・濃紺は初期版の条件。今回の比較は Studio の60秒・明るい工房を使い、既存版の方針書は保持した。
