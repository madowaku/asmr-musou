# v0.9 CRUNCH STUDIO 引き継ぎ

基準は `research/v0.8-flow` の `c1b535c917fc257a66b38e8fd7c8b2528a9eeb33`。GitHub のブランチ先端と一致。v0.8 の入口は `flow.html`。手元では同じコミットから `research/v0.9-crunch-studio` を分岐した。

## Phase A の基準

- `npm run check` に合格。素材ラボの構文チェック23本、切断形状203ケースに合格。
- `node tests/flow/spin.mjs` で円・逆回り・揺れる楕円・低速入力と、半円・直線・ジグザグ・タップ・長押しを確認。8の字は既存テストで判定保留。
- `node tests/flow/smoke.mjs` は seed 1 の4キャラ全員でボス撃破、切断フォールバック0、ブラウザエラー0。Lv2 は6.3〜8.8秒。
- 引き継ぎ資料では、ユーザーがSPINNERの吸い込み旋風と連続切断を評価している。v0.8 の評価シートと研究ログに包括的な人間試遊結果は未記入。この感想を他のキャラや全体の評価へ一般化しない。

## 残っている課題

大剣士・魔法使いの空き時間、Lv2 の早さ、SPINNER が最初の敵を壊した後の空振り、ゼリーを繰り返し切った際の三角形分割、群れとボスの音のバランス、Android実機での性能と操作感。ゼリーの戦闘側フォールバックは維持する。

既存の `GAME_DIRECTION.md` の濃紺・45秒は初期版の制作方針。v0.8 の比較には `docs/v0.8/FLOW_DESIGN.md` と `flow/game.js` のクリーム系・60秒制限（ボス撃破で早期終了）を使う。v0.9 の独立実験場は引き継ぎ資料の明るいクリーム系・時間制限なしを適用する。各版のルールや過去記録は維持する。

## 進行順

Phase B はロウ・ゼリー・石鹸の独立実験場。速度差、折り返し、停止圧縮を比較する。Phase C の本編投入、Phase D の3ステージ・図鑑、Phase E のキャラ美術は、実験場の音・変形・繰り返し触りたくなるかを人間が確かめてから判断する。

公開プレビューの Chrome モバイルエミュレーションではタッチの円4回から32刻み、4撃破。時間を進めて結果画面を表示し、ブラウザエラー0。
