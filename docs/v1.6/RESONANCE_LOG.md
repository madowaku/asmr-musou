# RESONANCE ATELIER / v1.6
公開用 Studio を含む deploy/production の 2a2427c から分岐。ルートの resonance.html が入口。外部音源、画像、API は使用しない。庭の素材は約1秒後に再生する。

## 操作の仮説
採用したのは指で結び、離して演奏する方式。押している間は小さな試奏、離したあとは結んだ順に音の主体が移る。速いスワイプでも入力点を線分で補間する。指を離す前にOSが入力を取り消したら選択を解除する。囲みは単体を狙う動作が長く、タップ＋長押しは解放操作が見えにくく、自動連結は旋律の順を選びにくいと予想し、今回は実装を見送った。比較試遊は未実施。

## 音と成長
C・D・E・G・Aの音列。列と高さで基本音を決め、ベルは長い減衰、水滴は短いピッチ下降と小粒音、鉱石は短い撥音と追奏、花は柔らかい倍音と遅れて重なる二音を持つ。素材ごとの声は位置から独立。リンク試奏は解放音の23%の振幅。音量調整は密度に応じたゲイン、ローパス、圧縮、発音上限の順に考えた。音量による成長を見送った。

累計6・16・30個で成長。単体への終止和音、余韻の追奏、接触判定の拡大を順に加える。最初から3個以上のフレーズには終止和音がある。20個解放しても発音間隔を確保し、最初から最後の素材まで約1.33秒。巨大オルゴールは外殻・内層・共鳴核を3フレーズずつ弾く。各フレーズの余韻は1.75秒。単体でも次へ進むため、ボスの手応えは試遊で要確認。

## 検証
Edge、390×844、タッチイベント。1個→6個→20個の解放数は累計27。ボス9フレーズ後に終幕、庭に戻ってLv.4。20個の操作前後に取得した先頭160描画フレームの間隔p95は13.6ms（デスクトップ上のエミュレーション）。ページ例外・コンソールエラー0。初期寸法確定前にCanvasを描く不具合を見つけ、最初の描画予約前にサイズを確定して再検証した。

同じ音源をOfflineAudioContextで48kHz・モノラルに描画。20個を70ms間隔で発音し、追奏と終止和音を追加した6秒の比較サンプル。ピーク −19.94 dBFS、絶対値1以上のサンプル0、300–3500Hzのエネルギー68.22%。これは一条件でのデジタル測定。スマホスピーカーの音質、快適さ、初見理解、リピート意向は未評価。
