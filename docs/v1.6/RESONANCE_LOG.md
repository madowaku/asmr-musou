# RESONANCE ATELIER / v1.6
公開用 Studio を含む deploy/production の 2a2427c から分岐。ルートの resonance.html が入口。外部音源、画像、API は使用しない。庭の素材は約1秒後に再生する。

## 操作の仮説
採用したのは指で結び、離して演奏する方式。押している間は小さな試奏、離したあとは結んだ順に音の主体が移る。速いスワイプでも入力点を線分で補間する。指を離す前にOSが入力を取り消したら選択を解除する。囲みは単体を狙う動作が長く、タップ＋長押しは解放操作が見えにくく、自動連結は旋律の順を選びにくいと予想し、今回は実装を見送った。比較試遊は未実施。

## 音と成長
C・D・E・G・Aの音列。列と高さで基本音を決め、ベルは長い減衰、水滴は短いピッチ下降と小粒音、鉱石は短い撥音と追奏、花は柔らかい倍音と遅れて重なる二音を持つ。素材ごとの声は位置から独立。リンク試奏は解放音の23%の振幅。音量調整は密度に応じたゲイン、ローパス、圧縮、発音上限の順に考えた。音量による成長を見送った。

累計6・16・30個で成長。単体への終止和音、余韻の追奏、接触判定の拡大を順に加える。最初から3個以上のフレーズには終止和音がある。20個解放しても発音間隔を確保し、最初から最後の素材まで約1.33秒。巨大オルゴールは外殻・内層・共鳴核を3フレーズずつ弾く。各フレーズの余韻は1.75秒。単体でも次へ進むため、ボスの手応えは試遊で要確認。

## 追加研究　素材と6人の試験場

初版の庭とボスを残し、lab/resonance/trial.html に自由演奏の試験場を追加。公開プレビューでは共通ビルドスクリプトが lab 以下を収録するため、正規の入口を lab/resonance/ に移した。以前の「ルートの resonance.html」はローカル互換入口。最初の配信はHTTP 200でも正式版のHTMLが返ったため、ページタイトルと実際の操作まで確認する。

5種の手続き音源は各振動モードが個別に減衰する。水琴窟風の水滴は発音直後に音程が下がり、木のカリンバは高次成分が早く消え、オルゴールは短い金属音が残る。クリスタルベルは非整数倍の成分、グラスハープはゆっくりした立ち上がりと微小なうなりを持つ。横位置を定位に、左右で異なる減衰インパルスを残響に使用。旋律・重ね和音・音の雨を選べる。端末固有の音量設定は操作しない。

階段と星座は折れ線、渦巻きは中心から外へ、花束は各花の5枚の花びらを同系和音に割り当てた。順序、スコア、拍の判定なし。既存Studioの入力モチーフを試験場用に縮小。大剣は横断後の遅れ、拳は距離順の跳ね、魔法は囲み内の発音、双剣は押している間の吸引と85ms間隔の演奏、ローラーは接触中の持続と音程移動。正式版の戦闘・成長バランスは移植していない。

比較は同じ5音を使い、音色、余韻、重ね方を一つずつ変更して聴ける。物理楽器の録音は使っていない。比較音の知覚音量合わせとブラインド試聴は未実施。暫定値の採否は実機試遊後に判断する。特に「最後の音のあと、もう少し待ちたいか」「旋風の各音が分かれるか」「ローラーの音が途切れず歌って聴こえるか」を観察する。

390×844のEdgeタッチ入力で6人全員の解放、4配置、比較操作を確認。ステレオ24kHzのオフライン検証（20素材×3声）でピーク0.14225、クリップ0。左右の信号差と最後の励振から0.5秒以上経過後の残響を検出。実機での耳当たり・旋律としての魅力は未評価。

## 双剣士とローラーの比較研究

試遊では旧双剣士の吸い込みが気持ちよく、旧ローラーのテルミンに似た音が面白いという感想を得た。その版（5add06f）のコードを維持して lab/resonance/duet.html に専用試験場を追加。新しい方式は採用保留。

双剣士は85msの発音機会と1.6秒の素材復帰を維持。吸い込み中心から素材までの距離を4帯域に分け、回転方向で5音の音列を反転する。回転方向は庭の中心を基準とする。12個から異素材による応答音、32個から上声を足す。6個以上を続けて解放した指を離すと最後の音を基準にグラスの3音が残る。

ローラーは横位置を2オクターブの音程、縦位置を水晶・水滴・グラスの倍音配分に割り当てる。移動を緩めて留めると圧縮が深まり、倍音が増す。素材境界を越えても同じ4発振器が鳴り続ける。離した後は振幅を減衰させ、左右で時間の異なる反射音を残す。Aはペンタトニック11音、Bは対数周波数上の連続音程、Cは各音の近くで傾きが緩やかになる単調連続曲線。直前のローラー軌跡はメモリ内で再演でき、位置・入力時間・圧力を同じ条件で比較できる。

Edge 390×844のタッチ入力で両方向の反転、Lv.3、長押しの圧縮、A/B/Cの再演開始・終了、例外ゼロを確認。101点の横座標でAは11音、B/Cは各101音程。ローラー単独のステレオ・オフライン検証で解放後の減衰と終端の無音を確認。スマホ実機・イヤホンでの新方式の聴感は未評価。次の試遊では、同じ軌跡を再演してから自由演奏に戻り、どの方式で自然に指を動かし続けたくなるかを比べる。

## 六人の演奏庭園

orchestra.html に六人を同じ音階で弾ける五つの研究舞台を追加した。音奏士は指順に鳴る水晶ベル、大剣士は弦を払うハープ、拳闘士は近くの素材に跳ねるマリンバ、魔法使いは集めた光を解放するパイプオルガン。双剣士の楽器はオルゴールの金属の歯を思わせる「音の万華鏡」、ローラーはグラスハープ。

旋風は85ms間隔と距離別の音域を維持。反転時は現在音から3音の向きが変わり、リングが金色になる。12個以降にハープの応答、32個以降に水晶ベルと万華鏡の高い和音が加わる。長い連鎖を離すと最後の音の上に余韻が残る。新しい庭のローラーはC固定。素材の境で倍音の混合比の変化をなだらかにし、押し込みで第4倍音を育てる。指を離すとそのときの音程に根音・五度・オクターブの短い余韻が重なる。旧duetのA/B/Cと同軌跡再演は比較用に保持。

響きの庭園は32個、音楽無双は96個の再生する素材と群れの解放和音。巨大オルゴールは外殻・内層・核を各12個解体すると終幕。六人の楽団は各奏者の直前の一節をメモリ内で反復し、別の奏者の演奏と重ねる。夜は素材を22個に絞り、マスターゲインを下げて時間無制限で弾ける。楽団の演奏は舞台を離れるかページを隠すと終了する。

390×844のタッチエミュレーションで6人のループ登録と一括停止、ボス36個の解体と再組立て、旋風両方向とLv.3、夜のローラーと消音を確認。6種60音と持続音を重ねたオフライン測定の片チャンネルピークは約0.171、余韻あり。スマホ本体やイヤホンでの新音色、重奏の聴き分け、反転の気持ちよさは次の人間試遊で評価する。
