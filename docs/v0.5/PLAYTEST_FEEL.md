# v0.5 FEEL LAB — 人間の試遊ガイドと評価シート

AI の客観検証（[研究記録](research_log/V05_FEEL_LOG.md)）とは別に、**人間の主観**を記録するためのシート。
ここに書く項目は、すべて**未検証**（人間が遊ぶまで分からない）。

## 開き方
- スマホ（推奨）：https://research-v0-5-feel.asmr-musou.pages.dev/feel.html （入口：`/play.html`）
- 比較用（v0.4）：同じビルドの `/combat.html`
- PC：`feel.html` を Chrome で開く（ダブルクリックでも動く）。
- 縦画面・片手で。イヤホン推奨。最初のタップで音が出る。

## 操作
| | 大剣士 | 拳闘士 | 魔法使い |
|---|---|---|---|
| 基本 | 斬りたい所をスワイプ | 殴りたい敵をタップ（連打でラッシュ） | 壊したい場所をタップ（なぞると連なる） |
| 長押し→離す | 大回転斬り | 圧縮パンチ | 巨大魔法（押している間は吸い込む） |
| その他 | タップで回転斬り | 殴った直後にはじくと、飛ばす向きを変えられる | — |

## 進め方
1. 3キャラを各2回以上遊ぶ。v0.4（`/combat.html`）も1回ずつ遊んで比べる。
2. 12秒と24秒で強化を選ぶ（時間は止まる）。2回目のプレイでは別の強化を試す。

## 最後に答えてほしいこと
1. 一番気持ちよかった強化と、物足りなかった強化。
2. 60秒の長さと、強化のタイミング（12秒・24秒）はちょうどよいか。
3. 3キャラで、まだ思いどおりに動かない場面はあるか（具体的に）。
4. 繰り返し遊ぶ理由として、何が足りないか（強化の種類、ボスの種類、記録、見た目など）。

## 未検証のまま残っていること
- 指でのスワイプ・タップの感触、ヒットストップの長さが自然か。
- 音の気持ちよさと疲れ（すべて合成音）。
- Android 実機での性能（PC で CPU を4倍遅くした条件でのみ計測）。
- キャラクターの絵はプログラムで描いた仮のもの。
