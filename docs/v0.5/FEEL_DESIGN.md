# ASMR MUSOU：FEEL LAB v0.5 — 操作快感と成長体験の再設計（総監督）

試遊ページ：`feel.html`（v0.4 の `combat.html` は比較のためそのまま残す）

## 0. 出発点（v0.4 の人間による試遊結果）
- 魔法使いが一番気持ちいい。一度に大量の敵を攻撃できるから。
- **キャラクターが思いどおりに動かず、爽快感を損なっている。**
- 敵の配置を考える余裕はない。考えずに遊んでも気持ちいい方が大事。
- 巨大ボスは好評（何度も攻撃できる手応え）。60秒はちょうどよい。
- 繰り返し遊ぶ魅力は、まだ足りない。

## 1. 中心となる考え
> **ASMR の快感を、自分の操作と成長でどんどん大きくする。**
> 適当に触っても大量に壊れる。狙うともっと壊れる。強化を選ぶと、壊れ方そのものが大きくなる。

v0.4 の中心仮説「一手で何体巻き込めたか」は残す。変えるのは、その一手を出すための**操作**と、一手を大きくしていく**成長**。
パズル（陣形の最適解、目安の手数、PERFECT）は主軸から外した。

## 2. 最優先：操作の再設計
### v0.4 の操作がずれた理由（原因の分析）
v0.4 は「キャラクターを基準にした相対操作」だった。なぞった形のまま、キャラクターが**自分のいる位置から**動く。
人は敵を見て、その敵の上をなぞる・タップする。すると攻撃はキャラクターの位置から始まり、見ていた敵とは別の場所で起きる。
同じ「人間らしい操作」をする自動プレイヤーで測ると、狙った敵に攻撃が届いた割合は v0.4 で 3〜24% しかなかった（§6）。

### v0.5 の文法：指が場所を決め、キャラクターが自分でそこへ行く
| | 基本 | 続けて | 長押し → 離す |
|---|---|---|---|
| **SLASHER 大剣士** | **スワイプ**：その向きに大きく斬る。刃はスワイプした場所を通る。指を離す前、52px 動いた時点で斬る | 長い・曲がるスワイプは続けて斬る。0.75秒以内の連続でコンボになり、刃が太く、音が少し高くなる | 大回転斬り（タップは回転斬り） |
| **CRUSHER 拳闘士** | **タップ**：その敵へ踏み込んで殴る（指が触れた瞬間に出る） | 連打はためておき、取りこぼさない。5発ごとにとどめの一撃（周りも潰す） | 圧縮パンチ（範囲を押し潰し、破片を飛ばす） |
| **CASTER 魔法使い** | **タップ**：その場所に魔法（マナなし。0.12秒の間隔だけ） | なぞると、115px ごとに魔法が連なる | 巨大魔法：押している間、魔法陣が指についてきて敵を吸い込む → 離すと一斉に弾ける |

補助（自動化してよい部分）：
- **距離の自動補正**：斬撃の帯が何にも当たらないときは、横へ最大150px ずれて、一番近い敵に合わせる。
- **自動照準**：拳闘士が殴った敵は、群れの多い方向（±40°）へ自動で飛ぶ。殴った直後に指をはじけば、その向きに飛ばせる（狙いたい人向け）。
- **吸着**：魔法の中心は、指の下の群れへ最大40px 寄る。
- **移動は自動**：キャラクターは攻撃する場所へ自分で踏み込む／ワープする。移動の操作はない。

### 手応えの表現
- 大剣士：刃の通り道に光る三日月を描き、0.1秒で振り抜く。切れる順番も刃の進行方向に合わせる（破断が刃を追いかける）。短いヒットストップ（14〜32ms、コンボで長くなる）。重さは低い「ドッ」と空気を切る音で出し、何かを斬ったときだけ刃の金属音を少し鳴らす。
- 拳闘士：左右の拳で音程を変える（ドン／ドッ）。殴られた敵は大きく潰れて飛ぶ。
- 魔法使い：魔法陣が花のように開く。雷は濡れた素材を伝う。主役は素材が壊れる音（v0.3 の音響エンジン）。

## 3. 第二段階：60秒の中で成長する
- 12秒と24秒の時点で、**時間を止めて2択**の強化を選ぶ（急がせない）。1プレイで2回。
- 強化は数値ではなく、**形・音・壊れ方**が変わるもの：

| キャラ | 強化 | 変わること |
|---|---|---|
| 大剣士 | 大斬撃 | 刃の幅が2倍、長さが1.35倍。三日月が金色になる |
| | 衝撃波 | 斬ったあと、刃の線から両側へ圧力の波が広がって砕く |
| | 二重斬撃 | 一振りが交差する二連斬りになる（二本目は桃色） |
| 拳闘士 | ラッシュ | 踏み込みが速くなり、一打ごとに隣の敵も殴る |
| | ぶっ飛ばし | 殴った敵が大きく潰れ、周りの敵もビリヤードのように弾け飛ぶ |
| | 追加破砕 | 飛んだ敵がぶつかるたび、その周りも砕ける（輪が連なる） |
| 魔法使い | 大魔法陣 | 範囲が1.6倍 |
| | 連鎖拡大 | 雷がどの素材も伝い、4段まで連鎖する（強化前は濡れた素材だけ、1段） |
| | 二重爆発 | 0.24秒後に、もっと大きな二度目が弾ける |

- 強化の余地を作るため、強化前の魔法使いは「雷1段・破片の連鎖なし」に抑えた（強化前でも一回のタップで約17体を壊す）。
- **強化のたびに雑魚の群れも厚くなる**（同時に出る数の上限 50 → 66 → 84）。強くなった攻撃に、もっと大きな群れをぶつける。

## 4. 戦闘の構成（約50〜60秒）
| 時間 | 内容 |
|---|---|
| 0〜12秒 | 雑魚の群れ（最初から画面中央にいる。後続は上から押し寄せる） |
| 12秒 | 強化 1/2（時間停止） |
| 12〜24秒 | 群れが厚くなる |
| 24秒 | 強化 2/2 |
| 24〜36秒 | さらに厚い群れ |
| 36秒〜 | 巨大な多層素材ボス（外殻の琥珀糖 → 中層の石鹸 → 核のスライム、外側からしか壊れない）。どのキャラも、ただ叩けばよい |
| 撃破時 | スローの大崩落 → 静かな余韻（約4秒）→ 結果 |
| 56秒 | 倒せなくても、ボスは自分から崩れる（罰なし） |

ボスの硬さ（叩く回数）：外殻 6、中層 4、核 24。拳闘士の拳はボスに1発で3回分の手応えを与える（一点を叩く分を補う）。

## 5. 繰り返し遊びたくなる仕掛け（結果画面）
- 一手の最大：強化前 → 強化後（「強くなった」を数字で見せる）
- 前回との差（+N 撃破）、自己ベストと NEW 表示（撃破、一手の最大、ボス撃破時間）
- **強化コレクション**（キャラごとに 3 つのうち何を試したか）。まだ試していない強化を名前で薦める
- 大きな「もう一回」、同じ戦場でキャラを変える、別の戦場

## 6. やめたこと（v0.4 から）
| やめたもの | 理由 |
|---|---|
| キャラクター基準の相対操作 | 狙った場所と攻撃の場所がずれる（人間の試遊と §6 の測定） |
| 魔法使いのマナ | 攻撃できない時間を作っていた（v0.4 では入力の 60% がマナ不足で無効） |
| 大剣士がチョークに弾かれる | 刃が止まると爽快感が切れる。v0.5 はひびが入るだけで、刃は止まらない |
| 陣形の名前、解き方のヒント、目安の手数、PERFECT | 考える余裕はない、という試遊結果。陣形は「群れの形」としてだけ残した |
| 魔法使いの風（押し流すだけで壊さない） | 仕込みの手間。v0.5 は全部の入力が何かを壊す |
