## 1. 作ったもの

| 項目 | 内容 |
|---|---|
| ルール | 中心に固定、360°回転のみ。前方 120°（±60°）に入った敵を自動で斬る。背面 60°（真後ろ±30°）に入ったアイテムを自動で受け取る |
| 判定距離 | 攻撃 205px（+12px/段階）、回収 200px、本体 46px（720×1280 座標）|
| 成長 | アイテム1種（剣の結晶）。取得ごとに 120→135→150→165→180°（最大 180°。背面 60° と重ならない）。剣の絵・軌跡の太さ・扇形の濃さ・到達距離も育つ |
| 敵 | ロウ（基本・大量）、氷（破片が 118px 以内の敵へ連鎖、最大8段）、ゼリー（弾みながら接近、破壊時に周りを押す）|
| 接触 | 敵が本体に触れたら消えてコンボが 0。HP・減点・ゲームオーバーなし |
| アイテム | 中心を通過したら消える（減点なし）。前で斬ると「壊れた…」の表示と、破壊音と違う小さなガラス音 |
| 操作 | 画面のどこでも左右ドラッグ。画面幅の半分で 180°、右へドラッグ＝時計回り。タップでは回らない。PC はマウスドラッグ |
| 進行 | 60秒固定構成（0–10 ロウのみ / 10.4 最初のアイテム / 20–35 混在 / 35–50 氷・ゼリーの大群 / 50–60 ラッシュ）。結果画面からすぐ再挑戦 |
| 得点 | 撃破10、アイテム30、連鎖撃破は +5×段数（最大+30）。コンボは2秒以内の連続撃破、アイテム取得では途切れない |
| 結果 | 総撃破数、最大同時撃破数、最大コンボ、アイテム取得数、アイテム破壊数、連鎖撃破、中心に触れた敵 |
| 研究モード | A 初めての背中 / B どちらを向く？ / C 破壊のご褒美（固定配置、何度でも）|
| 音 | 破壊は v0.3 の素材音響エンジン（共用）。回収は「ぽふっ」（低域の布）＋「こぽんっ」（上昇する泡）、成長は柔らかいチャイム、速い回転で小さな風切り。同時発音は間引き、ミュートあり |

共用したもの：`combat/world.js`（切断・断面・破片・パーティクル・素材イベント）、`lab/`（WebGL2 描画、素材、音響エンジン、輪郭）。**どれも変更していない。** SPIN 固有のコードは `spin/` だけ。

比較候補の自動回転型は `spin.html?mode=auto`（自動で回り、タップで向きを固定／解除）。UI からは選べない（仕様どおり、切り替え UI は作らない）。そのほか試遊比較用に `?rot=240`（半画面あたりの回転角）、`?invert=1`（ドラッグと逆向きに回る）。

## 3. ボットによる客観データ（60秒、シード1–3 の平均。`research/v05/sim.json`）

ボット：idle（何もしない）/ random（でたらめに回る）/ naive（一番近い敵を向くだけ。アイテムを気にしない）/ skilled（近いアイテムには背中を向け、それ以外は敵の多い方を向く）

| ボット | 得点 | 撃破 | 最大同時 | 最大コンボ | 取得 / 13 | 破壊 | 接触 | 最終の剣 | 最初のアイテム |
|---|---|---|---|---|---|---|---|---|---|
| idle | 1627 | 124 | 20 | 21 | 1.0 | 6.3 | 189 | 1段 | 3回とも破壊 |
| random | 3468 | 265 | 33 | 65 | 4.7 | 8.3 | 61 | 3.7段 | 取得2・破壊1 |
| naive | 4247 | 337 | 42 | 337 | 3.7 | 9.3 | 0 | 3.7段 | 取得2・破壊1 |

研究モード（シード1）：

| 場面 | idle | naive | skilled |
|---|---|---|---|
| A 初めての背中 | アイテム破壊 | アイテム破壊 | 取得 |
| B どちらを向く？ | 取得1（後ろから来た2個目）| 取得2 | 取得2 |
| C 破壊のご褒美 | 取得0・最大同時10 | 取得1・破壊1・最大同時12 | 取得2・最大同時15 |

### 読み取れること（客観。気持ちよさの判断ではない）

1. **何もしなくても壊れる（idle 124撃破）。** 氷の連鎖と、正面から来る敵だけで最低限の破壊は起きる。「何も考えずに遊んでも気持ちいい」の下地はあるが、接触 189 回でコンボはほぼ育たない。
2. **アイテムを意識するかどうかで、得点の差がほとんど出ない（naive 4247 対 skilled 4353）。** 原因は2つ：
   - 剣は4個で最大になるが、アイテムは13個出る。naive は「敵を向いたら、たまたま背中に来た」アイテムだけで平均3.7段まで育つ。
   - 剣が育つと、敵を向くだけでほぼ全部斬れる。naive は接触 0、コンボが途切れない。
   → **v0.1 の構成では「向きの選択を考える余地」が後半で薄い可能性が高い。** 人間の試遊で確かめたうえで、次の調整候補にする（§5）。
3. **最初のアイテムは 16秒ごろに判定距離へ届く。** 20秒以内に「背中で受け取る」発見を体験させる、という目標の時間には収まる。ただし敵を向き続けるだけの遊び方（idle / naive の一部）では最初のアイテムを壊す。研究モード A はこの「壊してしまう→背中なら取れる」を再現できている。
4. **研究モード B は naive と skilled の差が出ない。** 左の敵を向くと、右のアイテムが自動で背中に入る配置なので「向きだけで切り替えられる」の気づきにはなるが、迷いは生まれにくい。
5. **研究モード C は意図どおりの差が出る。** 2個取ると最大同時撃破 15、取らないと 10。
6. **「最大同時撃破」は氷の連鎖でふくらむ。** 0.2秒以内の連続撃破を「同時」として数えているため、氷の塊は1回の斬撃で 20〜40 になる。人間の体感の「一撃で壊した数」と合うかは試遊で確認する。

## 4. 不採用・失敗した方式（研究記録として保存）

| 方式 | 何が起きたか | 対応 |
|---|---|---|
| COMBAT LAB の物理（破片に重力）をそのまま使う | 真上から見たアリーナなのに、破片と粉が画面の下へ落ちて「横から見た絵」になった | SPIN だけ、破片の重力を 0、粉を 5% にし、減衰で滑って止まるようにした（`world.js` は変更せず、更新フックで上書き）。**代わりに、床で跳ねた破片の `impact` 音（崩れの余韻）がほぼ鳴らなくなった。** 余韻が足りなければ、破片が止まる瞬間に音を出す方式を検討する |
| 氷を琥珀糖に色を掛けて表現する | 琥珀色に青を掛けると茶色の塊に見え、氷に見えなかった | 琥珀糖の輪郭・物理・音のまま、表面と断面のテクスチャを氷に差し替えた（このページだけ）|
| 敵を画面外のアリーナ半径から直接出す | `world.js` が x>980 などを画面外として即削除するので、左右から来る敵が消えた | 半径 585px より外では「接近中の予約」として座標だけ動かし、内側に入った時点で実体化する |
| 生成画像の主人公（剣を持った絵）をそのまま使う | 剣を振る絵と、手に持った剣が二重になる | 鍔より上を切り取り、剣は別の画像で振る |
| 判定を「その瞬間の向き」だけで行う | 1フレームで大きく回すと、間の敵を飛ばしてしまう | 前フレームの向きから今の向きまでの掃引範囲で判定する。回収を先に判定し、1つの対象は1回だけ結果を適用 |
| 斬撃を一定間隔の当たり判定にする | 仕様の「理不尽な空白時間を作らない」に反する | 判定は毎フレーム連続。剣の振りは 0.6秒周期の見た目だけ |

## 5. 次の調整候補（実装していない。人間の試遊の結果で選ぶ）

- アイテムの数を減らす、または前半に寄せる（今は13個、4個で最大）
- 最大まで育ったあとのアイテムに別の価値を持たせる（一時的な大斬撃、回収の泡で背面を広げる など）
- 敵の流れを「正面の敵とアイテムが同時に来る」配置に寄せて、迷いを作る（研究モード B の改訂）
- 回転の感度（`?rot=`）、向き（`?invert=1`）、自動回転型（`?mode=auto`）の比較

## 6. ドキュメント・仕様とコードの食い違い（未解決のまま残したもの）

| 場所 | 食い違い | 対応 |
|---|---|---|
| 仕様 §4「氷」/ v0.3 の素材（`lab/materials/studies.js`）| v0.3 の8素材に「氷」はない（ロウ・ゼリー・石鹸・砂・チョーク・スポンジ・ビーズスライム・琥珀糖）| 琥珀糖の物理と音を使い、見た目だけ氷にした。**音は琥珀糖のまま。** 本物の氷の素材研究はしていない |
| 仕様 §3「回転量は画面幅の半分で180°」| 「画面幅」を、ゲーム画面（縦長キャンバス）の幅として扱った。スマホでは同じ、PC の横長画面ではキャンバス幅 | このまま |
| 仕様 §7「連鎖撃破：破壊数に応じたボーナス」| 具体値がない | 連鎖の段数に応じて +5×段（最大 +30）とした |
| 仕様 §6「最初の10秒で…」の固定構成 | 「固定」と「何度も遊ぶ」の両立のため、本編は構成（時間帯と素材）を固定し、方向と数はシードで変える。「もう一回」は別シード | 研究モード A/B/C は完全固定 |
