# ASMR MUSOU v1.4 SOUND ATELIER

## 試聴・試遊

- [音の比較試聴](../../studio/listen.html) は素材、キャラクター、場面を選び、同じイベント列をA・B・Cで再生します。単音、序盤、連続攻撃、大群、ボス、撮影、環境音、UIを選べます。
- [ゲーム](../../studio.html) では「設定 → 音響方式」で切り替えます。試聴ページの試遊リンクでも、直前の方式が引き継がれます。初期値はAです。
- 聴き比べでは最初に音量を固定し、ロウの単音、ゼリーの居合、スポンジの連続圧縮、琥珀糖の大群を順に試します。各方式で聞こえた素材、手前と奥の印象、途切れや疲れやすさを記録する想定です。

| 方式 | 実装 |
| --- | --- |
| A 既存の合成音 | 既存の素材合成・キャラ音・動的ミックス。従来に存在しないキャラ選択、解放、ステージ環境音は無音 |
| B Lumina SFX | 8素材の一撃・グレイン・余韻、優先した攻撃・UI・ボス音を採用したPCMに置き換え。圧縮は既存の圧力・解除カーブで乾いた質感または湿った質感を駆動 |
| C ハイブリッド | 同じ素材イベントの合成波形とPCMを一声の中で混合。攻撃・ボス音では既存の合成バスに軽いPCM層を加える |

大剣士は抜刀、断面の開き、滑りを別の音として扱い、既存の短いダッキングを保っています。双剣士は刃を左右に振り分け、回転の連続でピッチを少しずつ上げます。ローラーは最初の接触、押圧の持続、圧を離した際の減衰を分けました。撮影モードは環境音を止め、既存の英雄音量の減衰を引き継ぎます。B・Cの実戦用環境音は一度に該当する1ステージ分を読み込み、破壊が密集したときに下げます。

## 素材と空間の設計

| 素材 | 採用した破壊音の手掛かり | 環境音 |
| --- | --- | --- |
| ロウ | ワックスを含む糸と革の短い摩擦 | 工房の窓辺の空気 |
| ゼリー | 密閉容器のふたが離れる低めの吸着 | ガラス越しの静かな室内音 |
| 石鹸 | 短い陶器調の鋭い当たり | 温室の水滴 |
| チョーク | 加圧で陶器が割れる乾いた短い音 | 峡谷の薄い空気 |
| 砂 | 石に落とした砂の粒 | 乾いた草を渡る風 |
| スポンジ | 柔らかいフォームへの打音と湿った圧縮 | 石段に寄せる浅い波 |
| 粒入りスライム | 柔らかい膜を引いて離す音 | 研究所の低い機械空気音 |
| 琥珀糖 | 短く切り出した硬いガラスの破片 | ゆっくり変化する風の響き |

## 出所・再生成

Lumina SFX v1.5.0 の [固定コミット 81939e5](https://github.com/LuminaBench/lumina-sfx/tree/81939e56b880532b2cb094954a50c5aa7a2ea302) を開発用チェックアウトとして使用しました。ゲームには33個の加工済み音だけを入れています。上流のコード・スキル・レシピ集は同梱していません。音の利用条件は [Luminaの分割ライセンス](https://github.com/LuminaBench/lumina-sfx/blob/81939e56b880532b2cb094954a50c5aa7a2ea302/LICENSE) に従います。採用クリップに含まれる第三者録音は、上流カタログ上で全件CC0です。[音源マニフェスト](SOUND_SOURCES.json) には各音のレシピ、録音名、作者、元URL、ライセンス、加工パラメーター、WAVとPCMのSHA-256を記録しました。

```powershell
git clone https://github.com/LuminaBench/lumina-sfx.git C:\path\to\lumina
git -C C:\path\to\lumina checkout 81939e56b880532b2cb094954a50c5aa7a2ea302
node tools/sound-atelier/render.mjs C:\path\to\lumina C:\path\to\new-wav-folder
node tests/studio/sound-atelier.mjs C:\path\to\test-report
```

上流のリミックスCLIでWAVに書き出し、FFmpegで帯域・モノラル・サンプルレートを整えました。短音は24 kHz、環境と圧縮の持続音は12 kHzの16-bit PCMです。環境と圧縮はループ境界を重ねており、既存のステレオ位置、同時発音上限、連打集約、リミッターでミックスします。PCMをJavaScriptに格納するため、従来どおりローカルHTMLから試遊できます。効果音パックは約427 kB、プレイ中に追加する環境音は該当ステージの約81 kBです。8素材の合計は約1.08 MBです。音源の実行時生成はAとCの従来合成部分に限り、追加のLuminaランタイムや有料サービスは使っていません。

## 検証の範囲

オフラインでは8素材×7場面×3方式を同じタイムラインで比較しました。Aの素材ミックスは追加機能を接続しない従来エンジンとバイト単位で一致しました。Chromeのスマートフォン相当の表示・タッチ入力では、ゲーム内の設定切替、キャラごとのイベント、撮影中の圧縮、ボス音を含むステレオ録音まで確認しました。音の好み、素材の聞き分けやすさ、スマートフォン実機のスピーカーやイヤホンでの評価は、この試聴ページを使う人間の聴取項目です。

| Chromeでのボス場面録音 | A | B | C |
| --- | ---: | ---: | ---: |
| RMS | −29.7 dBFS | −30.8 dBFS | −29.1 dBFS |
| ピーク | −6.6 dBFS | −10.9 dBFS | −8.3 dBFS |
| クリッピング | 0 | 0 | 0 |
| 実戦の描画間隔 p95 | 13.5 ms | 13.4 ms | 13.5 ms |

- ボス場面の初回試作ではBの平均音量がAを約4 dB下回ったため、Bのボス各層だけを補正しました。リミッターの閾値は従来の値です。
- 撮影モードのローラーは、ブラウザのタッチから接触まで3.6 ms、接触イベントから音の予約まで0.2 msでした。48 kHzの処理ブロック予算は10.7 ms、ブラウザ報告のベースレイテンシは10 msです。予約時刻と物理スピーカーからの出音は別です。
- ローカルHTMLのタイトル表示までの中央値は、WORLD ATELIERが199 ms、SOUND ATELIERが219 msでした。合成バンクの準備をアイドル時間に分け、試聴ページの最初の音声初期化は前の計測の約528 msから約237 msになりました。初回操作の早さによって先行準備できる量が変わります。
- 既存の素材・5キャラ、居合、双剣士、ボス、ROLLERのテストが通過。旧素材ラボの4倍CPUテストでは初回8.6 msで8 ms基準を超え、個別再実行で7.5 msでした。
