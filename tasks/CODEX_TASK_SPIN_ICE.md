# Codex task: SPIN LAB ice textures (image generation only)

Use the built-in image generation tool (image_gen). Do NOT write or modify code. Only create PNG files under `assets/spin/src/`.
These are textures that get mapped onto small cuttable "ice" enemies seen from above in a cute, glossy, satisfying ASMR game. The texture is clipped by the enemy's polygon in code, so it MUST fill the entire square frame edge to edge (full-bleed, no background, no border, no object silhouette, no vignette to black). No text.

1. `assets/spin/src/ice_body.png` — square. Top-down close-up of a glossy pale-cyan ice block surface: translucent icy blue-white, faint internal crack lines, a few tiny trapped bubbles, a soft diagonal specular highlight toward the upper-left, slightly brighter centre. Bright and clean (it must read as "ice" at 60 px on a dark background), not grey.
2. `assets/spin/src/ice_xsec.png` — square. The freshly cut inside of the same ice: very clear, brighter, sparkling, crisp faceted fracture surface with fine white fracture ribs, cool cyan-white. Full-bleed.
