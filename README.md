# ASMR無双 / ASMR MUSOU v0.1

**敵を倒した感触そのものが報酬になる、45秒のストレス発散ブラウザゲーム。**

## 遊び方

1. `index.html` をChromeなどのブラウザで開く（外部サーバー不要）。
2. 「さわってスタート」を押す。
3. タップでパキッ、なぞって連続斬り、長押しでむぎゅっと潰す。
4. 45秒で3ウェーブ。最後に巨大ボス。得点よりも感触を楽しもう。

操作：マウス / タッチ / ペン。`🔊`で音を切れる。最初のユーザー操作でWebAudioを有効化するため、開始ボタンを押す前に音は出ない。音量を低めにして試すこと。

## 実装済み

- 720×1280の縦型Canvas 2D（リサイズ追従、外部ライブラリなし）
- ロウ殻、プチプチ、ゼリー、氷、ボス
- タップ、なぞり、長押し
- ヒビ、破片、連鎖、画面揺れ、コンボ、結果画面
- WebAudioで仮SEをリアルタイム生成（**実録ASMRではない**）
- オフライン動作可能（ファイルをローカルで開く場合）

## テスト

- `node --check game.js`：構文チェック
- Playwright Pythonがある環境なら `python tests/smoke.py` ：タイトル→開始→攻撃→長押し→スコア→結果画面を検証。テスト実行でプレビュー画像も生成する。

## オーケストレーション

Opus 5.5に [ORCHESTRATOR_BRIEF.md](ORCHESTRATOR_BRIEF.md) を読ませ、現在のプロジェクトフォルダを作業ルートとして渡す。Codexの委任用タスクは `CODEX_TASK_GAMEPLAY.md` と `CODEX_TASK_ART.md`。詳細な実行例はブリーフ内。

## 現状の限界

現在のキャラはCanvas描画の試作で、画像生成を実行した素材ではありません。音も合成テスト音。遊べることと、最終品質のASMRであることは分けて評価してください。
